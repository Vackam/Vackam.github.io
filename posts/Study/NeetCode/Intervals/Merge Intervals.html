최종 병합된 상태를 순서에 상관없이 제시하라

푸는 방법

이번 문제는 저번 Insert Interval과 달리 sorting이 안되어 있어서 sort를 하고 가야한다.

병합이 되어있는 가장 최신 것의 끝점보다 내 첫 점이 크다면 겹치지 않으므로 그냥 삽입, 그렇지 않다면 내 끝 점과 비교하여 큰 것을 선택하여 값을 취하면 된다. 병합된 것과 동일하게 동작한다.

다음은 코드이다.

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        // 됐다 치고
        sort(intervals.begin(), intervals.end());
        int n = intervals.size();

        vector<vector<int>> result;

        for (auto& i : intervals) {
            if (result.empty() || result.back()[1] < i[0]) {
                result.push_back(i);
            } else {
                result.back()[1] = max(result.back()[1], i[1]);
            }
        }
        return result;
    }
};

vector의 함수 중 back을 통해 가장 최신값을 불러오고, 이의 끝 점과 나의 첫 점 또는 끝 점을 비교한다.

결론

처음에는 슬라이딩 윈도우로 풀 수 있을 줄 알았는데, 겹침 판정이 빡셌다.

또한, 값을 수정하고 push_back으로 풀려하니 중복값에 대해서 대처가 어려웠다.

그래서 병합된 값에 추가할 때 -> 값 수정

새로 넣어야 할 때 -> push_back

이렇게 하니 잘 풀렸다.
