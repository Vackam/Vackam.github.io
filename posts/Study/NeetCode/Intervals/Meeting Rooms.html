미팅 시간이 겹치는 지 확인해라.

푸는 방법

sort하고 겹치는 지 확인하면 된다.

이것도 대충하면 되는데, 전에 있는 end 값이 지금 값의 start 값보다 큰 지 확인하면 된다.

다음은 코드이다.

class Solution {
public:
    bool canAttendMeetings(vector<Interval>& intervals) {
        int n = intervals.size();

        if (n < 2) return true;

        sort(intervals.begin(), intervals.end(),
            [](const Interval& a, const Interval& b) {
                return tie(a.start, a.end) < tie(b.start, b.end);
        });

        auto& prev = intervals[0];

        for (int i=1; i<n; ++i) {
            if (prev.end > intervals[i].start) return false;
            prev = intervals[i];
        }

        return true;
    }
};
