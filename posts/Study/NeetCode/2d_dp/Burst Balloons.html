Burst Balloons

2026-09-15 psdp

서론

| https://neetcode.io/problems/burst-balloons/question

풍선을 터뜨리면 터뜨린 풍선과 양 옆 값을 곱한 값을 얻을 수 있는데, 모든 풍선을 터뜨리어 해당 값의 최댓값을 찾으시오

푸는 방법

보자마자 dp 지만, 어려운 dp 답게 거꾸로 생각해야 한다.

만약 dp 테이블을 터뜨리면서 채워나가고자 하면 값이 뒤섞여 dp를 할 수가 없다.

그래서 다음과 같이 dp를 정의한다.

dp[l][r] = l~r 까지 모든 풍선을 터뜨린 경우 중 가장 큰 경우

이렇게 하고, l~r 사이 마지막으로 터뜨리는 풍선을 k (l <= k <= r)라고 하자.

그럼 마지막으로 터뜨리는 값이므로,

dp[l][r] = dp[l][k-1] + dp[k+1][r] + nums[k]*nums[l-1]*nums[r+1]이 되겠다.

그래서 작은 값부터 돌면 dp[1][end]에 답이 나오게 된다.

다음은 코드이다.

class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        vector<int> a(n+2, 1);
        for (int i=0; i<n; ++i) a[i+1] = nums[i];

        // dp[l][r]: l-1, r+1이 살아있을 때, [l, r]을 다 터뜨린 최대값
        // 즉, 마지막 요소를 터뜨리면 l-1 * r+1 * num
        vector<vector<int>> dp(n+2, vector<int>(n+2, 0));

        for (int len=1; len<=n; ++len) {
            for (int l=1; l+len-1 <= n; ++l) {
                int r = l + len - 1;
                for (int k=l; k<=r; ++k) {
                    dp[l][r] = max(dp[l][r], dp[l][k-1] + dp[k+1][r] + a[l-1] * a[k] * a[r+1]);
                }
            }
        }

        return dp[1][n];
    }
};

nums[0 - 1]을 써야 하므로 패딩을 준 a로 이전시켰다.

그래서 for문을 3개를 돌면서 작은 값부터 채워나가준다. 여기서 작은 값은 구간의 길이 기준이다.

결론

좀 어려운 dp는 다 이런 식이다.

아 기록 해볼까? -> 값이 오염됨.

뒤에서 돌아볼까? -> 뒤에서 돌면 값이 팽창해서 찾을 수가 없음

dp까지 하는데 O(n^3)인 것도 풀이에 걸림돌이 되었다.
