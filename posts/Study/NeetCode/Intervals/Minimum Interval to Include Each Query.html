Minimum Interval to Include Each Query

2026-08-18 psinterval

서론

| https://neetcode.io/problems/minimum-interval-including-query/question

속한 구간 중 가장 작은 구간을 각각 구하시오

푸는 방법

주어진 queries, intervals가 정렬되어 있다고 하자.

최소힙을 하나 구현하고, 그것의 원소는 (구간 길이, 끝값)을 가진다고 하자.

하나의 쿼리마다 다음과 같은 과정을 거친다.

  1. 쿼리가 해당 구간의 첫 값보다 크거나 같다면(속할 것이라 생각되면) 최소 힙에 넣는다.
  2. 해당 구간이 없을 때까지 반복한다.
  3. 그리고 최소 힙에서 끝값이 쿼리보다 작은 경우 전부 뺀다.
  4. 힙이 비어있을 경우 쿼리값은 -1, 비어있지 않을 경우 해당 값의 구간이다.

이게 왜 되나면

  1. 최소힙이기 때문에 조건을 만족하면서 처음 만나는 값이 최소라고 할 수 있다.
  2. 쿼리가 정렬되어 있다고 생각하기 때문에 자기보다 작은 끝값을 가지는 구간은 없앨 수 있다. 즉, 다신 안봐도 된다.
  3. 동일 값에 대해서는 한 번 더 힙에 남김으로 볼 수 있으므로 가능하다.

다음은 코드이다.

using pii = pair<int, int>;
class Solution {
public:
    vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
        sort(intervals.begin(), intervals.end());
        vector<pii> v;

        for (int i=0; i<queries.size(); ++i) {
            v.push_back({queries[i], i});
        }
        sort(v.begin(), v.end());

        priority_queue<pii, vector<pii>, greater<>> pq;
        vector<int> res(queries.size());

        int i = 0;

        for (auto& [Q, idx] : v) {
            while (i < intervals.size() && intervals[i][0] <= Q) {
                pq.push({intervals[i][1] - intervals[i][0] + 1, intervals[i][1]});
                ++i;
            }

            while (!pq.empty() && pq.top().second < Q) pq.pop();
            res[idx] = pq.empty() ? -1 : pq.top().first;
        }

        return res;
    }
}
