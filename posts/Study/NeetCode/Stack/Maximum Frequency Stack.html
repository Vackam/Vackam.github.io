frequent stack을 구현하라

푸는 방법

최대 20,000번의 호출이 있다고 하므로 한 번 할 때마다 탐색을 한다면 시간초과가 난다.

또한, value의 최대 값이 10억이기 때문에 오버플로우가 안 일어나게 조심해야 한다.

푸는 방법은 빈도수를 기록하는 것과 해당 빈도수에 따라 stack을 하나씩 두는 것이다.

다음은 코드이다.

class FreqStack {
    unordered_map<int, int> freq;
    unordered_map<int, stack<int>> group;
    int max_freq = 0;
public:
    FreqStack() {

    }
    
    void push(int val) {
        int f = ++freq[val];
        max_freq = max(max_freq, f);
        group[f].push(val);
    }
    
    int pop() {
        int x = group[max_freq].top();
        group[max_freq].pop();
        freq[x]--;
        if (group[max_freq].empty()) max_freq--;
        return x;
    }
};

즉, frequent 별 stack을 가지고, 그것을 기준으로 빼내기 시작한다.

기존에 있던 값을 pop을 안해도 되는 이유는 가장 큰 stack에서 빠진 뒤에는 자동으로 기존에 있던 값으로 돌아오기 때문이다.
