Ephemeral token

| https://ai.google.dev/gemini-api/docs/live-api/ephemeral-tokens?hl=ko

토큰, 값들을 사용할 때 항상 문제가 되고 걱정이 되는 게 탈취이다. 특히 요즘 같은 AI API 사용하는 시대에 키 한 번 잘못 탈취 당하면 10만원 20만원... 계속 나갈 수 있다. 그래서 사용하는 것이 임시 토큰(Ephemeral token)이다.

구글 API 에서는 다음과 같이 사용한다.

백엔드에 토큰 요청 -> 백엔드에서 gemini api에게 요청 -> live API에 대한 토큰 전송 -> 이를 프론트가 API 키 인 것처럼 사용

즉, 프론트가 API key를 모르더라도 아주 간편하게 사용할 수 있다.

또 1분 동안 호출이 없다면 자동으로 죽인다고 하니 아주 좋다.
