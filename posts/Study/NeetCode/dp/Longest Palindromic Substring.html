Longest Palindromic Substring

2026-08-04 psdp

서론

| https://neetcode.io/problems/longest-palindromic-substring/question

문자열 중 가장 긴 팰린드롬을 구하시오

푸는 방법

팰린드롬을 중앙에서부터 찾는 생각을 하면 된다.

주어진 s를 한 칸씩 전진시키면서 얘가 중앙일 경우에 가능한 지를 판단한다.

짝수형태와 홀수형태가 있는데, 이를 유의하여 진행하면 된다.

다음은 코드이다. 

class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int start = 0, max_len = 1;

        auto expand = [&](int l, int r) {
            while (l >= 0 && r < n && s[l] == s[r]) {
                if (r-l+1 > max_len) {
                    start = l;
                    max_len = r-l+1;
                }
                l--;
                r++;
            }
        };

        for (int i=0; i<n; ++i) {
            expand(i, i);
            expand(i, i+1);
        }

        return s.substr(start, max_len);
    }
};
