Valid Palindrome II

2026-10-21 pstwo_pointer

서론

| https://neetcode.io/problems/valid-palindrome-ii/question

한 문자를 지워서 팰린드롬을 만들 수 있는 지 확인하라.

푸는 방법

앞이랑 뒤에서 비교하면서 나아가되, 일치하지 않는 부분이 나오는 경우 그때부터 가능한 두 가지 경우를 비교하여 결론을 찾으면 된다.

다음은 코드이다.

class Solution {
    bool is_pal(const string& s, int l, int r) {
        while (l<r) if(s[l++] != s[r--]) return false;
        return true;
    }
public:
    bool validPalindrome(string s) {
        int l = 0, r = s.size() - 1;
        while (l<r) {
            if (s[l] != s[r]) return is_pal(s, l+1, r) || is_pal(s, l, r-1);
            l++; r--;
        }
        return true;
    }
};

결론

처음에는 start 부분에 있는 걸 지우는 걸 선택하고, 안되면 end를 지우는 것을 했었는데, 둘 다 가능한 경우이면서 end를 지우는 것이 맞는 경우를 찾지 못했다. 그래서 이런 세계선이 여러 개로 나뉘는 경우에는 모든 경우를 탐색할 수 있도록 하는 게 중요하다.
