2026-09-30 psmath

서론

| https://neetcode.io/problems/multiply-strings/question

내장된 함수를 사용하지 말고 곱셈을 구현하라

푸는 방법

num1[i] * num2[j]의 결과는 i+j+1 자리에 기여하는 것을 염두에 두고 풀면 된다.

다음은 코드이다

class Solution {
public:
    string multiply(const string& num1, const string& num2) {
        if (num1 == "0" || num2 == "0") return "0";

        int n = num1.size(), m = num2.size();
        vector<int> res(n + m, 0);

        for (int i = n - 1; i >= 0; --i) {
            for (int j = m - 1; j >= 0; --j) {
                int sum = (num1[i] - '0') * (num2[j] - '0') + res[i + j + 1];
                res[i + j + 1] = sum % 10;
                res[i + j]    += sum / 10;
            }
        }

        string out;
        out.reserve(n + m);
        for (int d : res) {
            if (out.empty() && d == 0) continue;   // 앞자리 0 제거
            out.push_back(char('0' + d));
        }
        return out;
    }
};

m+n의 자릿수만 확보해주면, 수학적으로 이를 넘을 수 없으니 vector공간도 확정이 된다. 대신 마지막에 0인 앞자리만 제거해주면 된다.

참고로 단순 stoi를 쓰면 200 자리인 경우에 문제가 생긴다.
