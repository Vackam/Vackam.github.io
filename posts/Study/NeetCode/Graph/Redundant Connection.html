사이클이 생기는 지점을 찾아라

푸는 방법

처음에 bfs로 인접리스트 만들어서 어떻게든 풀 수 있을 줄 알았다.

문제는 edges의 마지막 간선을 반환해야 한다는 점이다.

bfs 탐색에서는 그것을 알 수가 없고, 결국 탐색에서 사이클 되는 지점을 찾으면

해당 지점에서 다시 한 번 더 탐색을 해서 edges와 비교해야 한다.

이는 말이 안된다.

그래서 유니온 파인드로 edges를 하나하나 돌면서 중첩이 되는 부분을 찾는 것이 상책이다.

다음은 코드이다.

class Solution {
public:
    vector<int> findRedundantConnection(vector<vector<int>>& edges) {
        int n = edges.size();
        vector<int> parent(n+1);
        vector<int> size(n+1, 1);
        iota(parent.begin(), parent.end(), 0);

        auto find = [&](auto& self, int x) -> int {
            return x == parent[x] ? x : parent[x] = self(self, parent[x]);
        };

        for (const auto& e : edges) {
            int a = find(find, e[0]), b = find(find, e[1]);
            if (a == b) return e;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a;
            size[a] += size[b];
        }

        return {};
    }
};
