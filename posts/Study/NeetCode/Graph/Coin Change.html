Coin Change

2026-08-07 psdp

서론

| https://neetcode.io/problems/coin-change/question

배낭 문제인데, 개수는 최소로 해라.

푸는 방법

처음에 그리디로 했다가 최소 조건을 당연히 못맞추어 실패했다.

그럼 방법은 dp인데, 1부터 하나씩 기록하면서 코인 하나를 넣었을 때 값이 만족된다면 이를 갱신하는 것으로 하면 된다.

다음은 코드이다.

```cpp

class Solution {

public:

int coinChange(vector& c, int a) {

vector dp(a + 1, a + 1);

dp[0] = 0;

for (int i=1; i<=a; ++i) {

for (const auto& b : c) {

if (b<=i) {

dp[i] = min(dp[i], dp[i-b]+1);

}

}

}

return dp[a] > a ? -1 : dp[a];

}

};

```

dp 한 칸마다 코인을 돌면서 하나 넣을 수 있는 지 아닌 지를 확인한다. 갱신 가능하면 바로 갱신한다.

결론

처음에는 저렇게 세련된 코드가 아니라 막 풀었었다. 그렇게 수정을 가하다 보니 저 코드가 나오게 됐다.

dp는 사실 복잡한 점화식이건 간단한 점화식이건 내용만 맞으면 다 풀리는 것 같다.
