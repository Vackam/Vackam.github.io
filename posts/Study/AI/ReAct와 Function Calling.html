ReAct와 Function Calling

2026-10-28 공부

서론

에이전트에서 많이 사용하는 ReAct 방식과 Function Calling에 대해 알아보자.

본론

ReAct

Reasoning + Acting -> 추론과 행동을 하는 것이다.

유저에게 입력을 받으면,

이 입력에 대해 필요한 정보가 있는 지 추론하고

모델이 필요한 도구를 찾아서 실행 한 뒤

결과를 해석해서 답변한다.

즉, 이것을 하기 위해서는 필요한 도구를 정리해 둘 필요가 있다.

도구를 정리해 두어야 한다는 점에서 복잡하고, 추론을 해야되기에 속도가 줄어들 수 있다.

Fucntion Calling

이는 모델이 도구 호출을 어떤 형식으로 내보낼지에 대한 API 기능이다. 도구 호출의 출력 형식에 대해 다루며, 반복은 없다.

개발자가 도구 이름과 JSON 스키마를 넘기면 -> 모델이 미리 정해둔 출력 형식에 맞추어 출력을 하게 해준다.

OpenAI가 API 기능으로 내놓은 뒤 모든 주요 모델이 지원하게 되었다.

결국 둘이 함께 써야 함

ReAct 루프를 돌면서, Acting(Action) 파트를 function calling으로 해서 답을 일정하게 받아 오는 형태로 하면 된다.

결론

아마 이미 익숙히 쓰고 있는 기능일 것이다. 이런 것들을 기반으로 해서 다양한 ai agent 프로토콜이 나온 듯 하다.
