Regular Expression Matching

2026-09-16 psdp

서론

| https://neetcode.io/problems/regular-expression-matching/question

.과\*가 있는 문자열이 매칭 되는 지 확인하라

푸는 방법

.은 한 글자 조커이고, \*는 앞의 글자를 [0, inf)까지 반복할 수 있는 것이다.

앞에서부터 탐색하면서 dp 테이블을 채워나가는데,

\*인 경우 한 번 더 사용할 수 있는 지를 체크하고, 아닌 경우에는 매칭이되는 경우에만 dp를 참으로 한다.

다음은 코드이다.

class Solution {
public:
    bool isMatch(string s, string p) {
        int n = s.size(), m = p.size();

        vector<vector<bool>> dp(n+1, vector<bool>(m+1, false));
        dp[0][0] = true;

        auto match = [](char a, char b) { return b == '.' || a == b; };

        for (int i=0; i<=n; ++i) {
            for (int j=1; j<=m; ++j) {
                if (p[j-1] == '*') {
                    dp[i][j] = dp[i][j-2] || (i>0 && match(s[i-1], p[j-2]) && dp[i-1][j]);
                } else {
                    dp[i][j] = i>0 && match(s[i-1], p[j-1]) && dp[i-1][j-1];
                }
            }
        }
        return dp[n][m];
    }
};
