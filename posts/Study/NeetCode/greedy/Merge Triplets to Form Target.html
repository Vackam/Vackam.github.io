Merge Triplets to Form Target

2026-08-27 ps그리디

서론

| https://neetcode.io/problems/merge-triplets-to-form-target/question

특별한 연산을 적용 했을 때 target을 만들 수 있는 지 판단하시오

푸는 방법

주어진 배열을 순회하면서

target보다 작은 것을 만족하면 연산을 적용한다.

이후 끝났을 때, target이 되면 참 아니면 거짓이다.

넘어가는 tuple은 답이 될 수 없으므로 신경쓰지 않는다.

다음은 코드이다. 

class Solution {
public:
    bool mergeTriplets(vector<vector<int>>& triplets, vector<int>& target) {
        int x = target[0], y = target[1], z = target[2];

        int now_x = 0, now_y = 0, now_z = 0;
        for (const auto k : triplets) {
            int a = k[0], b = k[1], c = k[2];

            if (a <= x && b <= y && c <= z) {
                now_x = max(now_x, a);
                now_y = max(now_y, b);
                now_z = max(now_z, c);
            }
        }

        return (now_x == x && now_y == y && now_z == z);
    }
};
