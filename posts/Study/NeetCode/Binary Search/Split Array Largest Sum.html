Split Array Largest Sum

2026-11-09 psbinary_search

서론

| https://neetcode.io/problems/split-array-largest-sum/question

연속적인 sub-array로 자를 때, 가장 큰 값이 최소가 되게 하는 큰 값을 구하라.

푸는 방법

이진 탐색으로 전형적이게 풀면 된다.

초기 상한 값은 배열의 전체합으로 한다.

이후 이진 탐색을 돌면서 칸을 어디를 자를 지를 확인하고, 칸막이가 부족하면 start를 땡기고, 칸막이가 넉넉하면 끝점을 땡기면 된다.

다음은 코드이다.

class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        int s = 0, e = accumulate(nums.begin(), nums.end(), 0);
        int n = nums.size();

        while (s < e) {
            int i = 0;
            int mid = (s + e) / 2;
            int k_counter = 0;
            int sum_counter = 0;

            bool is_enough = true; 

            while (i < n) {
                if (sum_counter + nums[i] > mid) {
                    k_counter++;
                    sum_counter = 0;
                } else {
                    sum_counter += nums[i]; 
                    i++;
                }

                if (k_counter >= k) {
                    is_enough = false;
                    break;
                } 
            }

            if (is_enough) {
                e = mid;
            } else {
                s = mid + 1;
            }
        } 

        return s;
    }
};
