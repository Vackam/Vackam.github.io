클로저에 대해서

2026-10-29 공부

서론

클로저에 대해서 알아보자.

언어 클로저(Clojure)가 아니고, 클로저(Closure)이다.

언어는 함수형 언어의 정석이라서 다음에 게시글로 함께 공부해보도록 하자.

본론

함수를 작성할 때, 함수 안에 함수를 정의하는 경우가 있다. 이 경우 대부분 함수 내부 동작을 간단하게 하려고 하는 경우가 대부분이지만, 가끔 내부 함수 자체를 반환하는 경우가 있다.

다음과 같은 경우를 생각해보자.

def make_counter():
    count = 0             
    def counter():
        nonlocal count
        count += 1       
        return count
    return counter      

c = make_counter()     
print(c())  
print(c())

make_counter()는 내부 함수인 counter()를 반환한다. 이후 c = make_counter()를 통해 함수를 대입한 이후 print를 하고 있다.

만약 c = make_counter에 print(c())라면 counter()에 대한 정보를 출력할 것이다. c = make_counter() \n print(c()) 이기에, 동작을 생각해봐야 한다.

단순하게 생각하면, print 호출 시 마다 make_counter()()가 실행되어, 두 출력문 모두 값이 1이 나올 것이다. 일반적으로 함수 호출 후 지역 변수는 사라지니까, count가 매 호출 시 0일 것이니 1로 다시 시작할 것 같다.

하지만, 실제 출력을 1 \n 2가 나온다. count는 사라지지 않고, 호출할 때마다 값이 누적된다.

클로저(Closure)

이유는 내부 함수인 counter가 만들어질 때 자신이 사용하는 바깥 변수 count를 붙잡아 두기 때문이다. make_counter가 종료되어도 내부 함수가 변수를 참조하고 있으므로 메모리에서 값이 사라지지 않는다.

이처럼 자신을 감싼 함수의 변수를 기억하고 있는 함수를 클로저라고 한다.

클로저는 두 부분으로 이루어져 있다.

  • 함수의 코드
  • 함수가 만들어질 때 붙잡아 둔 바깥 변수들

그래서 위 코드의 동작을 확인해보면 다음과 같다.

  1. c = make_counter() 함수 한 번 호출 후, count = 0가 만들어지고, 이를 붙잡은 함수인 counter가 c에 저장된다.
  2. c()는 make_counter()를 실행시키지 않고, counter를 실행시킨다. 메모리에 있는 count를 1 증가 시킨다.
  3. c()도 동일하게 1 증가시킨다.

그럼 다음과 같은 코드에서는 어떻게 될까?

a = make_counter()
b = make_counter()
a()
a()
print(a()) # 3
print(b()) # 1 ​

make_counter()가 호출될 때마다 새로운 count가 만들어진다. 그래서 a와 b의 값이 다르게 된다.

Python에서는 nonlocal 을 붙이지 않으면 에러가 발생한다. 함수 안에서 처음 보는 변수에 += 1이라는 행위를 하려고 하니 에러가 발생한다. 즉, 바깥 변수를 참조하겠다는 선언을 하지 않으면 에러가 나는 것이다.

가장 익숙한 사용법

가장 익숙한 사용법은 데코레이터이다.

함수를 실행할 때, 부가적인 정보들을 넣어주고 싶을 때, 이 클로저의 개념이 없으면 성립하지 않는다.

결론

각 함수는 독립적으로 실행되지만, 실행할 때마다 어떤 정보를 저장하거나 참조해야 할 때 사용할 수 있도록 만든 기능이다.

단순한 코딩에서는 그리 사용할 일이 없겠지만, 복잡한 로직 등이 들어가면 편리한 기능일 것 같다. 실제로 데코레이터는 실험하는 사람들에게 필수적인 기능이니까 더욱 그러하다.

C++도 11부터 지원을 시작했고, 다른 언어들도 지원을 하니, 만약 필요한 경우 적극적으로 사용해보도록 하자.
