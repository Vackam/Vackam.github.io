Simplify Path

2026-10-18 psstack

서론

| https://neetcode.io/problems/simplify-path/question

path를 잘 만들어봐라.

푸는 방법

.. 연산 때문에 deque를 활용하였다.

또한, 중첩해서 /가 가능하기 때문에 그것을 걸러주기 위하여 크게 if/else로 나누어서 풀었다.

다음은 코드이다.

class Solution {
public:
    string simplifyPath(string path) {
        deque<string> s;
        int n = path.size();
        int i = 0;
        while (i < n) {
            if (path[i] == '/') {
                while (i < n && path[i] == '/') {
                    ++i;
                }

                if (i == n) break;
                else continue;
            } else {
                int old_i = i;
                while (i < n && path[i] != '/') {
                    ++i;
                }

                string new_s = path.substr(old_i, i - old_i);

                if (new_s == "..") {
                    if (!s.empty()) s.pop_back();
                } else if (new_s == ".") {
                    continue;
                } else {
                    s.push_back(new_s);
                }
            }
        }

        string result = "/";

        while (!s.empty()) {
            result += s.front() + "/"; s.pop_front();
        }

        // 이거 슬래쉬 하나 지울려고 이렇게 함.
        return result.substr(0, result.size() - 1 > 0 ? result.size() - 1 : 1);
    }
};
