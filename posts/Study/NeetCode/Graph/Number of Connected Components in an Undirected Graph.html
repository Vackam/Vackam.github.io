Number of Connected Components in an Undirected Graph

2026-07-30 ps그래프

서론

| https://neetcode.io/problems/count-connected-components/question

연결되어 있는 그래프의 개수를 세라

푸는 방법

Union Find 하면 된다.

size를 넣고 밸런스 있게 풀 수도 있지만 빠르게 하기 위하여 없애고 한다.

합치는 경우에만 전체 개수에서 달라지므로 count를 두어 빼면서 진행하였다.

다음은 코드이다.

class Solution {
public:
    int countComponents(int n, vector<vector<int>>& edges) {
        vector<int> parent(n, 0);
        iota(parent.begin(), parent.end(), 0);

        auto find = [&] (auto& self, int x) -> int {
            return x == parent[x] ? x : parent[x] = self(self, parent[x]);
        };

        int count = n;
        auto unite = [&] (int x, int y) -> void {
            x = find(find, x); y = find(find, y);
            if (x == y) return;
            count--;
            parent[x] = y;
        }; 

        for (const auto& a : edges) {
            unite(a[0], a[1]);       
        }

        return count;
    }
};
