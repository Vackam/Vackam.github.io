Remove Duplicates From Sorted Array

2026-10-24 pstwo_pointer

서론

| https://neetcode.io/problems/remove-duplicates-from-sorted-array/question

증가하는 수열에서 중복된 값을 제거하라.

푸는 방법

k를 두어 이를 [0..k)까지는 중복이 없는 상태라고 가정하자.

nums[i]와 nums[k-1]을 비교한다.

  1. 값이 같다면, 중복되는 값이므로 i를 증가시킨다.
  2. 다르다면, 새로운 값이 나온 것이므로 k 위치에 새 값을 주고, 증가시킨다.

그러고 k를 리턴 시키면 된다.

다음은 코드이다.

class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;
        int k = 1;
        for (int i=1; i<nums.size(); ++i) {
            if (nums[i] != nums[k-1]) {
                nums[k++] = nums[i];
            }
        }

        return k;
    }
};
