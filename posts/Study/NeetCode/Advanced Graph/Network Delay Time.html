Network Delay Time

2026-08-31 psAdvanced-Graph

서론

| https://neetcode.io/problems/network-delay-time/question

그래프에서 전파될 수 있는 가장 최솟값을 구하시오

푸는 방법

bfs로 최소 거리를 갱신하면서 풀었다.

계속 돌면서 거리가 갱신될 가능성이 있는 경우 q에 푸쉬해준다.

최종 끝났을 때, 처리되지 않은 노드가 있다면 에러 아니면 최댓값을 반환한다.

다음은 코드이다.

using pii = pair<int, int>;

class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        // bfs 돌면서 자신의 최소를 찍어내면 되는 거 아닌가.

        vector<int> visited(n + 1, -1);
        vector<vector<pii>> adj(n+1);
        queue<int> q;

        for (const auto& a : times) {
            adj[a[0]].push_back({a[1], a[2]}); // (위치, 비용); 
        }

        q.push(k);
        visited[k] = 0;

        while (!q.empty()) {
            auto a = q.front();
            q.pop();

            int target = visited[a];

            for (const auto& b : adj[a]) {
                if (visited[b.first] == -1 ||
                     visited[b.first] > target + b.second) {
                    visited[b.first] = target + b.second;
                    q.push(b.first);
                }
            }
        }

        int result = 0;
        for (int i=1; i<=n; ++i) {
            int a = visited[i];
            if (a == -1) return -1;

            result = max(result, a);
        }

        return result;
    }
};

문제는 거리가 음수일 때는 안 통한다는 점이다.

다른 풀이는 그냥 다익스트라를 박는 방법이다.

한 번 돌 때 최소임을 보장해주기 때문에, 꼼꼼하게 돌면서 체크하면 된다.

결론

bfs 응용으로도 풀 수 있고, 단순하게 다익스트라를 박아서 풀어도 된다.
