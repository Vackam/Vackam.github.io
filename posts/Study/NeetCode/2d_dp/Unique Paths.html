끝 점에 도달하는 경우의 수를 세시오

푸는 방법

2d로 하면 아주 쉽다.

고등학생 때 했던 것처럼 하나씩 번호를 새기면서 가면 된다.

다시 돌아가는 경우는 없으므로(오른쪽, 아래 제한) 그대로 하면 된다.

다음은 코드이다.

class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> v(m, vector<int>(n, 0));

        for (int i=0; i<m; ++i) {
            v[i][0] = 1;
        }
        
        for (int i=0; i<n; ++i) {
            v[0][i] = 1;
        }
    
        for (int i=1; i<m; ++i) {
            for (int j=1; j<n; ++j) {
                v[i][j] = v[i-1][j] + v[i][j-1];
            }
        }

        return v[m-1][n-1];
    }
};
