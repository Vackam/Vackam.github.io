bit 개수를 세는 배열을 반환하라

푸는 방법

관건은 1이 추가되었을 때 판정인데, 아예 이걸 회피해 버리면 편하다.

자기 것에서 2를 나눈 dp에서 판정하면 된다.

다음은 코드이다.

class Solution {
public:
    vector<int> countBits(int n) {
        vector<int> dp(n+1, 0);
        for (int i=1; i<=n; ++i) {
            dp[i] = dp[i >> 1] + (i & 1);
        }
        return dp;
    }
};
