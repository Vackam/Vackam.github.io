무적의 영어 단어를 찾아라.

푸는 방법

n이 입력되고, 중복을 허락하지 않은 문자열 s가 들어온다고 가정해보자.

s[i]에 대해, 문자열이 s[i]s[i+1] ... s[i+1]로 구성될 수 있으므로, 한 문자에 대해 다른 모든 문자가 적어도 n-1번씩 있는 경우가 존재해야 한다.

그러므로, n번 s를 출력하게 되면 모든 경우를 아우르면서 최소값이 되게 된다.

다음은 코드이다.

#include <bits/stdc++.h>

using namespace std;

int main() {
	int n; cin >> n;
  string s; cin >> s;

  while (n--) cout << s;
  return 0;
}

결론

푸는 데 좀 걸렸다. 아주 단순하게 생각해서 풀자.
