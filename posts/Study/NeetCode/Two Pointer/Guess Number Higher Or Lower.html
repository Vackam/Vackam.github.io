Guess Number Higher Or Lower

푸는 방법

이미 구현되어 있는 guess(int num)을 통해 binary search를 구현하여 풀면 된다.

다음은 코드이다.

class Solution {
public:
    int guessNumber(int n) {
        int s = 0, e = n;

        while (s < e) {
            int mid = (s + e) / 2;
            int a = guess(mid);

            if (a == 0) {
                return mid;
            } else if (a == -1) {
                e = mid;
            } else {
                s = mid + 1;
            }
        }    

        return s;
    }
};
