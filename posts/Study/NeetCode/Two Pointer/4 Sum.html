4개의 합을 찾아보자.

푸는 방법

순서가 상관없기 때문에 우선 정렬을 한다.

이후 i, j, l, r을 세워서 풀이를 시작한다.

각각의 역할을 다음과 같다.

  1. i는 정답 배열의 첫 값을 의미한다.
  2. j는 정답 배열의 둘째 값을 의미한다.
  3. l은 정답 배열의 셋째 값을 의미한다.
  4. r은 정답 배열의 넷째 값을 의미한다.

이때, i와 j는 이중 for문을 돌면서 값을 바꿔준다.

i가 [0, n-3)을 돌면서 값을 잡고, j는 [i+1, n-2)를 돈다.

이후 l = j+1, r = n-1로 선언하며 이 둘이 투 포인터 역할을 하게 된다.

i, j는 값이 중복되면 넘어가는 로직이 필요한데, 이는 두 값이 확정된 이후로 모든 경우를 살펴보기에 무조건 중복되는 값이 나오기 때문이다.

또한, 중복을 방지하기 위해 동일하게 l, r도 중복 스킵 로직이 필요하다.

다음은 코드이다.

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> res;
        int n = nums.size();
        sort(nums.begin(), nums.end());
        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i-1]) continue;          // i 중복 skip
            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j-1]) continue;  // j 중복 skip
                int l = j + 1, r = n - 1;
                while (l < r) {
                    long long s = (long long)nums[i] + nums[j] + nums[l] + nums[r];
                    if (s < target) l++;
                    else if (s > target) r--;
                    else {
                        res.push_back({nums[i], nums[j], nums[l], nums[r]});
                        while (l < r && nums[l] == nums[l+1]) l++;  // l 중복 skip
                        while (l < r && nums[r] == nums[r-1]) r--;  // r 중복 skip
                        l++; r--;
                    }
                }
            }
        }
        return res;
    }
};
