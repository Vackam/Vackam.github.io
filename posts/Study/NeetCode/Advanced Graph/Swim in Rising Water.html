Swim in Rising Water

2026-09-03 psAdvanced-Graph

서론

| https://neetcode.io/problems/swim-in-rising-water/question

첫 칸부터 마지막 칸까지 가는 경로 중 큰 값이 가장 작은 길을 찾아서 큰 값을 반환하시오

푸는 방법

우선 dfs에 visited 배열 대신 자기가 가진 길 중에서 가장 작은 값을 들고 있는 best 배열로 분기를 판단해서 풀었다.

내 코드는 더러우니 이것을 푸는 아름다운 방법을 공부하는 식으로 해보자.

1. 다익스트라

그래프에서 경로 찾기 문제로 바꿔 풀 수 있다. 그 값을 수위 최댓값으로 생각하면 된다.

다음은 코드이다.

class Solution {
public:
    int swimInWater(vector<vector<int>>& grid) {
        int n = grid.size();
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        vector<vector<int>> dist(n, vector<int>(n, INT_MAX));
        priority_queue<array<int,3>, vector<array<int,3>>, greater<>> pq;

        dist[0][0] = grid[0][0];
        pq.push({dist[0][0], 0, 0});

        while (!pq.empty()) {
            auto [d, x, y] = pq.top();
            pq.pop();
            if (d > dist[x][y]) continue;            // 낡은 항목
            if (x == n-1 && y == n-1) return d;      // 꺼낸 순간이 확정

            for (int i = 0; i < 4; ++i) {
                int nx = x + dx[i], ny = y + dy[i];
                if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                int nd = max(d, grid[nx][ny]);       // 덧셈이 아니라 최댓값
                if (nd < dist[nx][ny]) {
                    dist[nx][ny] = nd;
                    pq.push({nd, nx, ny});
                }
            }
        }
        return -1;
    }
};

우선순위 큐를 세워 계속 초기화를 할 수 있게 하고, 덧셈으로 판별하는 대신 max로 판별하게 한다. 이렇게 할 경우 x == n-1 && y == n-1인 순간이 정답이 된다.(큐 성질에 의해)

2. 유니온 파인드

int m = n*n;
vector<bool> active(m, false);

for (int t = 0; t < m; ++t) {                // 수위를 1씩 올린다
	int id = pos[t], x = id / n, y = id % n;
	active[id] = true;
	for (int i = 0; i < 4; ++i) {
		int nx = x + dx[i], ny = y + dy[i];
		if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
		if (active[nx * n + ny]) unite(id, nx * n + ny);
		}
	if (find(0) == find(m - 1)) return t;    // 시작과 끝이 붙는 순간
}
return -1;

일부만 발췌했다.

아이디어가 상당히 재밌는데, [0, m) 까지 숫자를 늘려가며 유니온 파인드를 진행한다.

그러면 경로가 합쳐지다가 어느 시점에서 마지막 칸과 첫 칸이 합쳐지는 경우가 발생하는 데, 그때가 바로 정답인 수위이다.

즉, 앞에서 작업만 해주면 리니어 서치 느낌으로 빠르게 된다.
