Reverse Linked List II

2026-11-13 psLinked_List

서론

| https://neetcode.io/problems/reverse-linked-list-ii/question?list=neetcode250

연결 리스트에서 정해진 구간만 반전시켜라.

푸는 방법

전형적인 연결리스트 문제이다. 이러한 문제는 총 3개를 동시에 다룬다고 생각하면 된다. 전의 값, 현재 값, 다음 값.

그래서 반전 자체는 단순하게 진행하면 된다. 세 개를 들고 있으면서 방향만 바꾸어주면 된다.

문제는 3가지 케이스가 나온다는 점인데 반전시키는 경우가

  1. head가 시작점일 경우
  2. tail이 끝점일 경우
  3. 중간에 잘 있는 경우

위와 같은 경우를 나누어서, 마지막 포인터 처리만 잘 해주면 간단하게 풀린다.

다음은 코드이다.

class Solution {
public:
    ListNode* reverseBetween(ListNode* head, int left, int right) {
        if (left == right) return head;
        ListNode* previous = nullptr;
        ListNode* copy_head = head;

        int i = 1;
        while (i != left) {
            ++i;
            previous = copy_head;
            copy_head = copy_head->next;
        }
        // -------------------- 저장용 --------------------
        ListNode* now = copy_head->next;
        ListNode* pre = copy_head;

        for (int j=0; j<right - left; ++j) {
            ListNode* now_next = now->next ? now->next : nullptr;
            now->next = pre;
            pre = now;
            now = now_next;
        }

        if (previous)
            previous->next = pre;
        else 
            head = pre;
        if (now)
           copy_head->next = now;
        else
           copy_head->next = nullptr;
           
        return head;
    }
};

이런 류의 문제는 무조건 첫 head를 기억해두자. 이것을 반복해서 사용하는 경우가 잦다.
