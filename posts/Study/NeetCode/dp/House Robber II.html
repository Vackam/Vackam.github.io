집이 원형으로 붙어있을 때 강탈할 방법을 찾으시오

푸는 방법

House Robber

이거랑 같은데, 첫 집과 마지막 집 조건만 챙기면 된다.

dp 라는 타이틀을 가지고 있으니 dp를 사용한다고 치면,

1번집을 무조건 턴 dp1 하나,

1번집을 안 턴 dp2 하나를 세워서 풀면 되겠다.

이후는 dp1에서는 마지막 집을 선택하지 않고, dp2에서는 마지막 집을 선택하거나 하지 않으면 된다.

다음은 코드이다. 

class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n <= 2) return *max_element(nums.begin(), nums.end());
        vector<int> dp1(n+1, 0);
        vector<int> dp2(n+1, 0);

        dp1[1] = nums[0];
        dp1[2] = dp1[1]; // 2번 선택 안함.

        dp2[2] = nums[1]; // 1번 선택 안함.
        // dp의 인덱스는 집 번호 1번 2번
        
        for (int i=3; i<n; ++i) {
            dp1[i] = max(dp1[i-1], dp1[i-2] + nums[i-1]);
            dp2[i] = max(dp2[i-1], dp2[i-2] + nums[i-1]);
        }
        dp1[n] = dp1[n-1]; // 마지막 선택 못함.
        dp2[n] = max(dp2[n-1], dp2[n-2] + nums[n-1]); // 둘 중에 하나
        
        return max(dp1[n], dp2[n]);
    }
};
