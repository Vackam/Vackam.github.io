주어진 n에 대해서 피보나치 수열이 있을 때, 이를 두 집합으로 나눈다. 이때, 두 집합의 합은 동일하면서 크기는 가장 크도록 하라.

푸는 방법

피보나치는 자신의 이전 숫자와 저번 숫자를 더한 합이므로, 3개씩 내려가면서 후보를 선택해나가면 된다.

다음은 코드이다.

#include <bits/stdc++.h>

using namespace std;

int main() {
  int n; cin >> n;

  vector<int> a, b;

  int k = n;
  while (k >= 3) {
    a.push_back(k);
    b.push_back(k-1);
    b.push_back(k-2);
    k-=3;
  }

  if (k==2) {
    a.push_back(1);
    b.push_back(2);
  }

  cout << a.size() << "\n";
  for (int x : a) cout << x << " ";
  cout << b.size() << "\n";
  for (int x : b) cout << x << " ";

  return 0;
}

이렇게 피보나치 수열의 특성을 이용해서 진행하면 된다.

결론

애드 혹 문제라서 특징을 잘 생각하면서 진행해야만 한다.
