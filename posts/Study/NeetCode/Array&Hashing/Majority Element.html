Majority Element

2026-10-06 psarray

서론

| https://neetcode.io/problems/majority-element/question

과반수 넘게 존재하는 원소를 찾아라

푸는 방법

무조건 과반수 넘는 게 있다고 한다.

이때 사용하는 알고리즘이 있다는 데, 그것을 적용하면 된다.

다음은 코드이다

class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int target = nums[0];
        int count = 1;
        
        for (int i=1; i<nums.size(); ++i) {
            if (target == nums[i]) {
                count++;
            } else {
                count--;
            }

            if (count == 0) {
                target = nums[i];
                count = 1;
            }
        }

        return target;
    }
};

결론

저 알고리즘이 과반수 넘는 수에 대해서 무조건 가능하기 때문에 성립한다.

Boyer-Moore Majority Vote Algorithm 이라고 한다.
