Online Stock Span

2026-10-17 psstack

서론

| https://neetcode.io/problems/online-stock-span/question

하나씩 주어지는 값에서, 지금까지 보다 작은 게 몇 개인지 세라

푸는 방법

그냥 vector 세우고 들어올 때마다 작은 것을 세려 하면 O(n^2)을 가지게 된다.

그래서 어떻게든 기억을 하면서 가야 한다.

그리고 span은 자기보다 큰 값에 막히니까 stack 을 활용하여 풀면 좋다.

다음은 코드이다.

class StockSpanner {
    stack<pair<int, int>> st;
public:
    StockSpanner() {
        
    }
    
    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        } 
        st.push({price, span});
        return span;
    }
};

결론

처음에 작은 모든 것을 세는 줄 알고 복잡하게 해야겠다 했는데, 영어 독해를 잘못한 거였다.
