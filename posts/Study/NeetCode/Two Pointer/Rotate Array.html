Rotate Array

2026-10-28 pstwo_pointer

서론

오른쪽으로 밀어보자.

푸는 방법

k를 n안으로 한 다음, 전체 배열을 뒤집고, 앞의 k 개를 뒤집고, 이후 나머지를 뒤집으면 된다.

다음은 코드이다.

class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;
        reverse(nums.begin(), nums.end());          // 전체 뒤집기
        reverse(nums.begin(), nums.begin() + k);    // 앞 k개 뒤집기
        reverse(nums.begin() + k, nums.end());      // 나머지 뒤집기
    }
};

결론

처음에 O(n) space 로 풀었다가 이 풀이로 풀었는데, 시간은 동일하게 나온다. 솔직히 공간 O(n)까지는 괜찮지 않나 싶다.
