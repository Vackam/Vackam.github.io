Remove Element

2026-10-05 psarray

서론

| https://neetcode.io/problems/remove-element/question

배열에서 val 값을 전부 제거하라.

푸는 방법

제거가 아예 없던 것처럼 해야 한다.

그래서 새로운 배열을 만드는 것으로 해결하기로 했다.

다음은 코드이다.

class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        vector<int> result;

        for (const auto& a : nums) {
            if (a == val) continue;
            result.push_back(a);
        }

        nums = result;

        return result.size();
    }
};
