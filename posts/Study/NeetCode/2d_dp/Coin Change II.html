Coin Change II

2026-09-09 psdp

서론

| https://neetcode.io/problems/coin-change-ii/question

동전을 중복 조합으로 뽑아서 가능한 경우를 서술하시오

푸는 방법

dp로 풀어야 하는 데 축을 잘 잡아야 한다.

for문을 어떻게 도느냐가 중요한데, 코인을 기준으로 돌았다.

코인을 기준으로 돌면서, 1, ... i - 1, i, ... amount 가 있다고 했을 때,

i - 1번 코인까지 탐색한 것은 i-1번 코인까지 사용해서 만들 수 있는 경우를 다 센 것이다.

다음은 코드이다.

class Solution {
public:
    int change(int amount, vector<int>& coins) {
        // 이건 1차원 dp 해서 해야하는 걸 텐데 
        vector<int> dp(amount + 1, 0);
        dp[0] = 1;
        for (int c : coins) {
            for (int i=c; i<=amount; ++i) {
                dp[i] += dp[i-c];
            }
        }
        
        return dp[amount];
    }
};

dp는 i를 만드는 방법 수로 해석한다.

dp[0]를 아무것도 안세는 경우로 하나 세우고, 코인을 가장 바깥에 두어 탐색을 시작한다.

이렇게 되면 중복 없이 해결할 수 있다.

결론

점화식이 어렵다. 이게 dp는 진짜 생각나면 1분 컷이고 생각 안나는 순간 망하는 거 같다.
