Set Matrix Zeroes

2026-09-26 psmath

서론

| https://neetcode.io/problems/set-zeroes-in-matrix/question

0으로 크레이지 아케이드를 해보자.

푸는 방법

새로 덮어쓴 0을 카운팅 안하고 어떻게 영향을 끼칠 것인지 고민해야 한다.

당연히 단순하게 queue에 전부 박아 놓은 다음 푸는 방식이 있다.

하지만, 문제에서는 공간복잡도O(1)을 하라고 권장하기에 더 생각을 해보자.

queue로 가면 최악의 경우 O(m*n)이다. O(m+n)으로 풀려면 rows[i], cols[i]로 배열을 만들어서 여기가 0인 지 아닌 지를 판단하게 하면 된다.

이걸 활용해서 주어진 matrix 자체를 체커로 사용하면 된다.

다음은 코드이다.

class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        bool col0 = false;  // 0번 열 전체를 0으로 만들어야 하는지

        // 1) 마킹
        for (int i = 0; i < m; ++i) {
            if (matrix[i][0] == 0) col0 = true;
            for (int j = 1; j < n; ++j) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 2) 역순으로 채우기 (0행이 마지막에 처리되도록)
        for (int i = m - 1; i >= 0; --i) {
            for (int j = n - 1; j >= 1; --j) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0)
                    matrix[i][j] = 0;
            }
            if (col0) matrix[i][0] = 0;
        }
    }
};
