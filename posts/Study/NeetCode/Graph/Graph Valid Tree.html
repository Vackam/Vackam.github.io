유효한 트리인지 확인하라

푸는 방법

인접리스트를 만든 다음, dfs로 vistied 체크를 하면서 탐색한다. 이때 새로운 노드를 탐색할 때마다 카운트를 세준다. 이후 카운트가 전체 개수와 동일하지 않을 경우 false를 뱉는다.

이게 가능한 이유는 트리의 성질 때문이다. 트리는 간선의 개수가 노드의 개수보다 딱 하나 작아야 한다. 그리고 트리인 경우 순회할 시 어떤 노드에서 출발하든 지 모든 노드에 도달할 수 있어야 한다. dfs 순회를 했을 때, 사이클이 생겼다는 것은 한 노드가 탐색이 안된다는 뜻이고(간선의 개수 제한) 이것이 마지막 cnt 조건에 걸려 false를 뱉게 된다.

다음은 코드이다.

class Solution {
public:
    bool validTree(int n, vector<vector<int>>& edges) {
        if ((int)edges.size() != n-1) return false;

        vector<vector<int>> adj(n);
        for (const auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        vector<bool> visited(n, false);

        int cnt = 0;
        auto dfs = [&](auto&& self, int now) -> void {
            visited[now] = true;
            ++cnt;
            for (int nxt : adj[now]) {
                if (!visited[nxt]) self(self, nxt);
            }
        };
        dfs(dfs, 0);

        return cnt == n;
    }
};
