푸는 방법

dp[i]를 "앞에서 i글자까지 잘랐을 때의 경우의 수"라고 정의하자. 인덱스가 아니라 길이다. 이렇게 두면 dp[0]은 빈 문자열이 되고, 빈 문자열을 해석하는 방법은 1가지니까 dp[0] = 1이다. 이 칸이 패딩 역할을 하면서 dp의 영원한 적수인 i-2 음수 인덱스 문제가 사라진다.

이제 dp[i]를 채울 때, 마지막 글자를 어떻게 떼어낼 것인지만 물어보자. 떼는 방법은 두 가지뿐이다.

  1. 마지막 한 글자만 떼서 문자 하나로 본다.
  2. 마지막 두 글자를 떼서 문자 하나로 본다.

1번이 되려면 그 글자가 '0'이 아니어야 한다. 0에 대응되는 문자가 없으니까. 되면 남은 앞부분이 i-1글자이므로 dp[i-1]을 더한다.

2번이 되려면 두 글자를 숫자로 만든 값 two가 10 이상 26 이하여야 한다. 10 미만은 "02"처럼 앞에 0이 붙은 꼴이라 두 글자로 묶을 수 없고, 27 이상은 대응 문자가 없다. 되면 dp[i-2]를 더한다.

마지막 줄 덕분에 return 0으로 중간에 튀어나갈 필요가 없다. 한 번 0이 박히면 그 뒤는 0 + 0이라 끝까지 0으로 흘러간다.

dp[1]은 루프가 i=2부터 도니까 미리 채운다. 첫 글자가 '0'이면 0, 아니면 1이다. n == 1이어도 루프가 안 돌고 dp[1]이 그대로 반환되므로 예외 처리가 필요 없다.

"1123"
dp[0] = 1
dp[1] = 1  // "1"
dp[2] = 2  // '1' 혼자 + "11"  → dp[1] + dp[0]
dp[3] = 3  // '2' 혼자 + "12"  → dp[2] + dp[1]
dp[4] = 5  // '3' 혼자 + "23"  → dp[3] + dp[2]

"100"
dp[0] = 1
dp[1] = 1  // "1"
dp[2] = 1  // '0' 혼자 불가, "10" 가능 → dp[0]
dp[3] = 0  // '0' 혼자 불가, "00" 불가 → 0

다음은 코드이다.

class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();
        vector<int> dp(n+1, 0);
        dp[0] = 1;
        dp[1] = (s[0] != '0');

        for (int i=2; i<=n; ++i) {
            if (s[i-1] != '0') dp[i] += dp[i-1];
            int two = (s[i-2] - '0') * 10 + (s[i-1] - '0');
            if (two >= 10 && two <= 26) dp[i] += dp[i-2];
        }    
        return dp[n];
    }
};
