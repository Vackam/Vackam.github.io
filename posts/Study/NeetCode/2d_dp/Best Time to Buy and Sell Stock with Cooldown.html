Best Time to Buy and Sell Stock with Cooldown

2026-09-08 psdp

서론

| https://neetcode.io/problems/buy-and-sell-crypto-with-cooldown/question

쿨타임이 존재할 때, 사고 파는 것의 최대 이익을 구하시오.

푸는 방법

모든 칸에서는 3가지 경우가 가능한데,

  1. 코인 보유하고 있는 상태
  2. 코인을 판 상태
  3. 아무것도 안 한 상태(쿨타임일 수도 코인을 들고 있을 수도)

이 세 가지를 계속 들고 다니면서 마지막에 비교하면 된다.

다음은 코드이다.

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();

        int hold = -prices[0], free = 0, cool = 0;
        for (int i=1; i<n; ++i) {
            int now_hold = max(hold, free - prices[i]); // 샀을 때
            int now_free = max(free, cool); // 가만히 있을 때
            int now_cool = hold + prices[i]; // 팔았을 때

            hold = now_hold;
            free = now_free;
            cool = now_cool;
        }

        return max(free, cool);
    }
};
