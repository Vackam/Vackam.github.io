Surrounded Regions

2026-07-28 ps그래프

서론

| https://neetcode.io/problems/surrounded-regions/question

바둑처럼 상대편을 먹었을 때 오셀로처럼 뒤집어라.

푸는 방법

새로운 벡터를 만드는 것이 아니고 참조로 받은 보드를 반환하기에 visited 배열처럼 사용하면 된다.

바깥쪽에 위치안 O를 기준으로 bfs 탐색을 하면 된다.

바깥에서 탐색해서 이어진 곳을 \'#\'으로 마크하고, 해당하지 않는 \'O\'는 그대로 둔다.

이후 배열 전체를 돌면서 'O' -> 'X', '#' -> 'O' 로 바꿔주면 된다.

다음은 코드이다.

class Solution {
public:
    void solve(vector<vector<char>>& board) {
        constexpr int dx[4] = {1, -1, 0, 0};
        constexpr int dy[4] = {0, 0, 1, -1};
        int n = board.size(), m = board[0].size();

        queue<pair<int, int>> q;
        auto push = [&](int x, int y) {
            if (board[x][y] != 'O') return;   // 벽이거나 이미 방문
            board[x][y] = '#';                 // 넣는 순간 마킹
            q.push({x, y});
        };

        for (int j = 0; j < m; ++j) { push(0, j);   push(n - 1, j); }
        for (int i = 0; i < n; ++i) { push(i, 0);   push(i, m - 1); }

        while (!q.empty()) {
            auto [x, y] = q.front(); q.pop();
            for (int i = 0; i < 4; ++i) {
                int nx = x + dx[i], ny = y + dy[i];
                if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
                push(nx, ny);
            }
        }

        for (auto& row : board)
            for (char& c : row)
                c = (c == '#') ? 'O' : 'X';
    }
};
