LFU 를 구현하라.

푸는 방법

자료형을 두 개를 운용해야 한다.

(key, {value, freq, iterator}를 들고 다니는 map 하나와

(freq, list<int>)를 들고 다니는 map을 운용해야 한다.

전자를 A 후자를 B라고 하자.

B는 freq별로 해당하는 값이 무엇이 있는 지를 저장하고 다닌다.

빈도수가 1인 애들의 집합을 list<int>, 2인 애들을 list<int>... 이렇게 저장하고 다닌다.

빈도수에 새로운 값이 들어올 때는 문제 조건에서 동일한 빈도수의 경우 LRU를 사용하라 했으므로 앞에 넣어주는 push_front를 진행한다.

이를 통해 A는 B의 list<int>에서 자기 자신의 위치를 기억하게 한다. 이것이 iterator이다.

그래서 A는 key를 주게 되면 value, freq, iterator를 가지고 있으므로 이를 수정하여서 빈도수를 체크하면 된다.

이를 위해 보조 함수 touch를 사용한다.

touch(key)는 key에 대한 get, put 연산이 들어왔을 때 그것의 freq를 업데이트 해주고, B에 있는 list<int>에서 제거하면서 최소 빈도수를 체크하는 역할을 한다.

이때 최소 빈도수는 조건에서 단순히 전 값에서 +1만 하면 되는데, 이는 전의 값이 한 칸 올라가므로 무조건 존재하기 때문이다.

다음은 코드이다.

class LFUCache {
    struct Node {
        int value, freq;
        list<int>::iterator it;
    };

    int cap, min_freq = 0;
    unordered_map<int, Node> nodes;
    unordered_map<int, list<int>> freq_list;

    void touch(int key) {
        Node& n = nodes[key];
        auto& old_list = freq_list[n.freq];
        old_list.erase(n.it);
        if (old_list.empty()) {
            freq_list.erase(n.freq);
            if (min_freq == n.freq) min_freq++;
        }
        n.freq++;
        freq_list[n.freq].push_front(key);
        n.it = freq_list[n.freq].begin();
    }
public:
    LFUCache(int capacity) : cap(capacity) {
        
    }
    
    int get(int key) {
        auto f = nodes.find(key);
        if (f == nodes.end()) return -1;
        touch(key);
        return f->second.value; 
    }
    
    void put(int key, int value) {
        if (cap == 0) return;

        auto f = nodes.find(key);
        if (f != nodes.end()) {
            f->second.value = value;
            touch(key);
            return;
        } 

        if ((int) nodes.size() == cap) {
            auto& lst = freq_list[min_freq];
            int victim = lst.back();
            lst.pop_back();
            if (lst.empty()) freq_list.erase(min_freq);
            nodes.erase(victim);
        }

        min_freq = 1;
        freq_list[1].push_front(key);
        nodes[key] = {value, 1, freq_list[1].begin()};
    }
};
