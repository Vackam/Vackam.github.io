점프를 뛰어서 마지막 칸에 도달할 수 있는 지 확인하라.

푸는 방법

처음에는 bfs 방식으로 풀었다.

방문한 칸인 지 확인하고, 그 칸에서 갈 수 있는 칸을 전부 삽입해서 다음 라운드에 진행.

이렇게 해서 q를 전부 비우기 전에 도달하면 true, 아니면 false로 했다.

다음은 코드이다.

class Solution {
public:
    bool canJump(vector<int>& nums) {
        int goal = nums.size() - 1;
        if (goal < 1) return true;

        vector<bool> visited(goal + 1, false);
        queue<int> q;

        q.push(0);
        visited[0] = true;

        while (!q.empty()) {
            auto a = q.front();
            q.pop();

            for (int i=1; i<=nums[a]; ++i) {
                if (a + i >= goal) return true;
                if (!visited[a + i] && nums[a+i] != 0) {
                    visited[a+i] = true;
                    q.push(a+i); 
                }
            }
        }

        return false;
    }
};

다른 풀이로는 그리디하게 푸는 방법이 있다.

도달할 수 있는 칸을 보고, 가장 끝까지 가서 생각하는 것이다.

그렇게 마지막까지 순회를 하면 성공, 아니면 실패로 한다.

다음은 코드이다.

class Solution {
public:
    bool canJump(vector<int>& nums) {
        int reach = 0;
        for (int i=0; i<nums.size(); ++i) {
            if (i > reach) return false;
            reach = max(reach, i + nums[i]);
        }    
        return true;
    }
};

결론

bfs 풀이도 시간이 그리 오래걸리지 않아서 괜찮다고 생각했는데, 그리디가 확실히 더 깔끔했다. bfs로 푼 이유는 만약 5칸 앞으로 갈 수 있는데 정답이 2칸만 가서 다른 칸을 들렀다 가는 경우가 있을 거 같아서 그랬는데, 넘어가는 거를 아예 신경 안써도 되니까 그리디 풀이가 더욱 좋은 거 같다.
