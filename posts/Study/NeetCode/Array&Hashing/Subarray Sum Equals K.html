Subarray Sum Equals K

2026-10-13 psarray

서론

| https://neetcode.io/problems/subarray-sum-equals-k/question

subarray 중 합이 k인 것들의 개수를 찾으시오

푸는 방법

현재 값을 갱신시키며, 원하는 타겟 값이 있는 지 확인한다.

이때 확인한 것을 기록하면서 지나가면 된다.

다음은 코드이다.

class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> freq{ {0, 1} };

        int cur = 0, result = 0;
        for (int x : nums) {
            cur += x;
            auto it = freq.find(cur - k);
            if (it != freq.end()) result += it->second;
            ++freq[cur];
        } 

        return result;
        
    }
};
