Cheapest Flights Within K Stops

2026-09-05 psAdvanced-Graph

서론

| https://neetcode.io/problems/cheapest-flight-path/question

정해진 횟수 안에 최솟값으로 src to dst 하는 값을 찾아라

푸는 방법

처음에 dfs로 접근 했다가 시간초과로 에러가 났다.

풀이는 벨만-포드 방식을 변형하는 것이다.

기존 벨만-포드 알고리즘은 최단 거리를 찾기 위해 n-1번을 반복한다. 그 이유는 최단 거리기 때문에 같은 곳을 반복해서 가지 않을 것이기 때문이다. (?)

이 문제에 적용하면 우리는 최대 k번을 지나다닐 수 있기 때문에 n-1이 아닌 k를 상한으로 두고 알고리즘을 돌리면 답이 나오게 된다.

다음은 코드이다.

using pii = pair<int, int>;
class Solution {
public:
    int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
        const int INF = 1e9;
        vector<int> dist(n, INF);
        dist[src] = 0;

        for (int i=0; i<=k; ++i) {
            vector<int> next = dist;
            for (const auto& f : flights) {
                int u = f[0], v = f[1], w = f[2];
                if (dist[u] != INF && dist[u] + w < next[v])
                    next[v] = dist[u] + w;
            }
            dist = next;
        }
        return dist[dst] == INF ? -1 : dist[dst];
    }
};
