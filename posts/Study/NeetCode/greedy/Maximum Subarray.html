Maximum Subarray

2026-08-19 ps그리디

서론

| https://neetcode.io/problems/maximum-subarray/question

가장 값이 큰 subarray의 합을 구하시오

푸는 방법

subarray 자체를 구하는 것이 아니라 값만 기억하면서 나오면 된다.

그리디 스타일로 내 차례가 되면 내가 무조건 포함되면 된다.

만약 전 값들이 음수로 나왔을 경우에는 나랑 합치면 무조건 손해니까 subarray를 나부터 시작하고, 양수인 경우 subarray를 잇는다.

다음은 코드이다.

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        if (n <= 1) return nums[0];

        int result = nums[0];
        int temp = nums[0];

        for (int i=1; i<n; ++i) {
            const auto& target = nums[i];
            // 왜냐면 무조건 선택할 거임.
            // 그래서 temp가 0보다 작으면 버리고 쓰기, 크면 무조건 쓰기
            temp = temp > 0 ? temp + target : target;

            result = max(temp, result);
        }

        return result;
    }
};

결론

처음에는 2차원 배열로 가능한 것들을 탐색하고자 했는데, 끊김에 대한 표현이 안되어서 실패했다.

방금 생각한 걸로는 구간합으로 풀 수 있을 것 같다.

구간합을 구한 다음, 가장 큰 값을 선택하면 되겠다.

하지만, 시간이

구간합 구하기 + 2중 for문 돌면서 가장 큰 값 찾기

이렇게 되므로 위 풀이보다 더 오래 걸릴 것이다.
