Majority Element II

2026-10-12 psarray

서론

| https://neetcode.io/problems/majority-element-ii/question

원소의 개수가 전체의 3분의 1을 넘는 것들을 전부 찾아라

푸는 방법

1/3이 중점이므로, 정렬을 한 뒤에 2/3지점까지 탐색하여 가능한 경우만 추출했다.

다음은 코드이다.

class Solution {
public:
    vector<int> majorityElement(vector<int>& nums) {
        vector<int> result;
        sort(nums.begin(), nums.end());
        int n = nums.size();

        int i = 0;
        int target = INT_MAX;
        while (i <= (2*n) / 3) {
            if (target == nums[i]) {
                ++i; continue;
            }
            target = nums[i];

            int last = i + (n/3);

            if (nums[last] == target) {
                result.push_back(target);
                i = last + 1;
            } else {
                i += 1;
            } 
        }

        return result;
    }
};
