Insert Interval

2026-08-12 psinterval

서론

| https://neetcode.io/problems/insert-new-interval/question

새로운 구간이 하나 왔을 때, 병합 가능할 시 병합된 구간을 구하라.

푸는 방법

새로운 구간의 시작(이후 start)보다 구간의 끝이 작은 것들은 result에 넣어두고 넘어간다.

이후 겹치는 부분이 시작되면 새로운 구간의 끝(이후 end)을 넘지 않는 구간을 계속 탐색한다. 여기서 end는 기존 구간의 중간에 속해도 된다. 병합을 하기 때문이다.

그렇게 돌면서 갈 수 있는 끝까지 간 다음에 나머지 처리를 하면 된다.

start와 end를 기존 구간의 값들과 비교하면서 갱신하지만, 사실상 start는 처음에 한 번, end는 마지막 한 번 비교가 중요하다.

다음은 코드이다.

class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
        vector<vector<int>> result;
        int i = 0, n = intervals.size();

        while (i<n && intervals[i][1] < newInterval[0]) {
            result.push_back(intervals[i]);
            ++i;
        }

        int start = newInterval[0], end = newInterval[1];
        while (i<n && intervals[i][0] <= end) {
            start = min(start, intervals[i][0]);
            end = max(end, intervals[i][1]);
            ++i;
        }
        result.push_back({start, end});


        while (i<n) {
            result.push_back(intervals[i]);
            ++i;
        }

        return result;
    }
};

결론

사실상 깡구현이다. 럭셔리한 풀이가 있다고 기대하지 말고 깡구현 할 줄 알도록 하자.
