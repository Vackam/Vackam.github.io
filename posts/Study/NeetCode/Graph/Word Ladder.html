Word Ladder

2026-08-01 ps그래프

서론

| https://neetcode.io/problems/word-ladder/question

시작 단어와 주어진 단어 리스트에서 경로를 찾아 마지막 단어까지 도달할 수 있는 지 확인하라.

푸는 방법

단순하게 모든 단어에 대해 한 글자 다른 인접리스트를 만들어 탐색하게 했다.

다음은 코드이다.

class Solution {
public:
    int diff(const string& a, const string& b, const int& size) {
        int counter = 0;
        for (int i=0; i<size; ++i) {
            if (a[i] != b[i]) counter++;
        } 

        return counter;
    }

    int ladderLength(string b, string e, vector<string>& v) {
        // 일단 있는 지 없는 지 부터 확인을 해야 함.

        int pos = find(v.begin(), v.end(), e) - v.begin();
        int size = v.size(); 
        int w_size = v[0].size();
        if (pos == size) return 0; // 예외처리

        // adj 그래프 그리면 될 거 같은데.
        // 나랑 한 글자 차이나는 사람들을 adj 로 하고
        // bfs 탐색해서 찾으면 굿 아니면 제끼기

        vector<vector<int>> adj(size); // 자기 이웃을 인덱스로 표현

        for (int i=0; i<size-1; ++i) {
            for (int j=i+1; j<size; ++j) {
                const auto& a = v[i]; 
                const auto& b = v[j]; 

                if (diff(a, b, w_size) == 1) {
                    adj[i].push_back(j);
                    adj[j].push_back(i);
                }
            }
        }

        queue<int> q;
        int result = 1;
        vector<bool> visited(size, false);

        // 여기서 처음인 애들이 갈 수 있는 곳 확인.
        for (int i=0; i<size; ++i) {
            if (diff(b, v[i], w_size) == 1) q.push(i);
        }

        while (!q.empty()) {
            result++;
            auto turn = q.size();

            for (int i=0; i<turn; ++i) {
                auto a = q.front(); q.pop();
                if (v[a] == e) return result;

                visited[a] = true;

                for (const auto& k : adj[a]) {
                    if (visited[k]) continue;
                    q.push(k);
                }
            }
        } 

        return 0;
    }
};

당연히 속도가 느리다. 그래서 다음과 같은 방식을 생각해볼 수 있다.

1. 인접리스트 안 만들고 하나씩 치환해보기.

단어의 길이가 짧다고 생각했을 때, 굳이 안 만들고 소문자 26개를 한 번씩 치환해보면서 리스트에 있으면 큐에 넣고 아니면 제끼면 된다.

2. 양방향 bfs

끝 단어에서 돌리고, 시작 단어에서 돌려서 중간에 만나도록 한다.

이렇게 되면 시간이 반으로 줄어들게 된다.

결론

어렵긴 한데, 시간 제한이 빡빡하지 않아서 풀 수 있었던 것 같다.
