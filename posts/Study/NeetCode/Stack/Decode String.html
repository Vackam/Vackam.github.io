푸는 방법

숫자 스택과 string stack, 그리고 cur string 하나를 둔다.

이후 돌면서 다음 규칙을 따른다.

  1. 숫자일 경우 num에 계속 추가한다. (두 자리 이상 값일 때를 위해)
  2. [인 경우, num을 push하고, cur string도 push 한다. 이후 두 값을 초기화 한다.
  3. ]인 경우, 이전 num과 strs를 가져오고 이를 붙여준다.
  4. 아닌 경우 cur string을 업데이트 한다.

다음은 코드이다.

class Solution {
    
public:
    string decodeString(string s) {
        stack<int> counts;
        stack<string> strs;
        string cur;
        int num = 0;
    
        for (char c : s) {
            if (isdigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                counts.push(num); strs.push(cur);
                num = 0; cur.clear();
            } else if (c == ']') {
                string prev = strs.top(); strs.pop();
                int k = counts.top(); counts.pop();
                while (k--) prev += cur;
                cur = move(prev);
            } else {
                cur += c;
            }
        }
        return cur;
    }
};
