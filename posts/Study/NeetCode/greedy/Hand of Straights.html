배열을 만들 수 있는 지 확인하라

푸는 방법

우선 정렬하여 값을 저장하는 map으로 각 원소의 개수를 파악한다.

이후 가장 앞에 있는 값을 가져온 다음 group size 하나씩 돌면서, 내가 그룹을 이룰 수 있는 값이 충분히 존재하는 지를 확인한다.

없으면 false, 되면 true를 반환한다.

다음은 코드이다

class Solution {
public:
    bool isNStraightHand(vector<int>& hand, int groupSize) {
        int n = hand.size();
        if (n % groupSize != 0 || groupSize <= 0) return false;

        map<int, int> cnt;
        for (int x : hand) cnt[x]++;


        while (!cnt.empty()) {
            auto [x, c] = *cnt.begin(); // map은 정렬되어 있음. 키 밸류 
            for (int k=0; k<groupSize; ++k) {
                auto it = cnt.find(x + k);
                if (it == cnt.end() || it->second < c) return false;
                it->second -= c;
                if (it->second == 0) cnt.erase(it);
            }
        }

        return true;
    }
};
