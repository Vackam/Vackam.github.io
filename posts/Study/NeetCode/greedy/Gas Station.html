Gas Station

2026-08-23 ps그리디

서론

| https://neetcode.io/problems/gas-station/question

차를 타고 갈 때 원으로 되어있는 동네를 모두 들를 수 있는 시작 지점을 찾아라.

푸는 방법

우선 gas와 cost의 차를 minus라는 벡터에 저장해두자.

이후 한 칸씩 돌면서 minus의 값들을 result에 더해나간다.

만약 result가 0보다 작다면 가능한 경우가 없는 것이다.

이렇게 더하면서 현재 남은 연료양을 체크한다.

남은 연료량이 음수가 된다면, 그 구간을 지나오는 순간 음수가 되어서 빠져나오지 못한 다는 뜻이므로, 시작 인덱스를 해당 인덱스보다 하나 크게 설정한다.

다음은 코드이다.

class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        vector<int> minus(n);
        
        for (int i=0; i<n; ++i) {
            minus[i] = gas[i] - cost[i];
        }

        int result = 0;
        int tank = 0;
        int index = 0;

        for (int i=0; i<n; ++i) {
            result += minus[i];
            tank += minus[i];

            if (tank < 0) {
                index = i+1;
                tank = 0;
            }
        }

        return result < 0 ? -1 : index;
    }
};
