Capacity to Ship Packages Within D Days

2026-11-05 psbinary_search

서론

| https://neetcode.io/problems/capacity-to-ship-packages-within-d-days/question

컨베이어 벨트에 적재되어 있는 순서대로 넣어야 하고, 이를 정해진 기간 내에 운송해야 할 때, 적어도 필요한 무게 제한이 몇 인지 구하라.

푸는 방법

정렬하면 안되고, 적어도 필요한 적재 용량이기 때문에 매개변수 binary search를 하면 손쉽게 풀린다.

다음은 코드이다.

class Solution {
public:
    int shipWithinDays(vector<int>& weights, int days) {
        int n = weights.size();

        int e = 0;
        for (const auto a : weights) {
            e += a;
        }

        int s = 0;

        auto gimotti = [weights, n, days](int mid) -> bool {
            int sum = 0;
            int day_counter = 0;
            for (int i=0; i<n; ++i) {
                if (weights[i] > mid) return false;
                sum += weights[i];

                if (sum > mid) {
                    day_counter++;

                    sum = weights[i];
                }
            }

            if (day_counter >= days) return false;
            return true;
        };

        while (s < e) {
            int mid = (s + e) / 2;

            if (gimotti(mid)) {
                e = mid;
            } else {
                s = mid + 1;
            }
        } 

        return s;
    }
};

순서대로 보아야 하므로, 단순 for문을 돌면서 체크해줬고, 만약 mid 보다 큰 값이 나온다면 안되는 경우이므로 바로 false를 반환하도록 했다. 또한, day_counter를 두어서 날짜 제한을 지킬 수 있도록 하였다.
