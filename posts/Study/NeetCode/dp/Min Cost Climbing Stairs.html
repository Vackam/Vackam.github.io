Min Cost Climbing Stairs

2026-08-03 psdp

서론

| https://neetcode.io/problems/min-cost-climbing-stairs/question

최소한의 값으로 계단을 오르는 법을 제시하라

푸는 방법

dp로 단순하게 풀면 된다.

내 두 칸 전에서 올라오는 게 좋은 지, 한 칸 전에서 올라오는 게 좋은 지를 비교하자.

다음은 코드이다.

class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = cost.size();
        if (n < 2) return 0;
        vector<int> dp(n+1, 0);    

        // 1까지는 0임
        for (int i=2; i<=n; ++i) {
            dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]);
        } 

        return dp[n];
    }
};
