First Missing Positive

2026-10-14 psarray

서론

| https://neetcode.io/problems/first-missing-positive/question

첫번째로 빠진 양수 값을 찾아라

푸는 방법

배열은 음수도 포함되어 있고, 모든 값이 차있는 상태에서 목표하는 양수 하나만 빠진 형태도 아니라서 정렬 후 중복값을 제거한 후에 시도하는 것으로 해결했다.

다음은 코드이다.

class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {

        sort(nums.begin(), nums.end());
        nums.erase(unique(nums.begin(), nums.end()), nums.end());

        int l = 1;

        for (int i=0; i<nums.size(); ++i) {
            if (nums[i] <= 0) continue;
            if (nums[i] == l) {
                ++l;
            } else {
                return l;
            }
        }

    }
};

하지만, 문제에서 O(n), O(1)의 시간 복잡도와 공간 복잡도를 요구했다.

이를 해결하기 위해선 주어진 배열 자체를 테이블로 사용해야 한다.

배열의 크기를 n이라고 할 때, 비둘기 집의 원리의 따라 목표하고자 하는 값은 n 이하임을 알 수있다.

ex)

target = 3;

nums = {-2, -1, 0, 1, 2, 77, 999, INT_MAX};
-> n = 8, n >= 3;

// 항상 n보다 작음이 보장된다.

그러므로, 주어진 배열의 [1, n)까지를 양수 인덱스로 사용하면서, 필요없는 음수 값들을 제끼면서 사용하면 된다.

다음은 코드이다.

class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums[i], nums[nums[i] - 1]);
            }
        }
        for (int i = 0; i < n; ++i) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
};

배열을 순회하면서, 1 <= nums[i] <= n이면서, nums[자기 자리] != 자기 자리(nums[i]), 아직 자기 자리에 들어가지 않은 경우에 swap을 진행해 준다. 이 마지막 조건을 통해서 중복을 걸러준다.

이렇게 정리해둔 다음에는 다시 한 번 순회를 돌면서 1보다 크게 차이나는 곳을 찾으면 정답이다.

결론

생각할 게 많은 문제여서 좋았다.

하지만, 실제 시험에서는 첫번째 풀이를 사용할 것 같다. 두번째 풀이는 알아도 떠올리기 쉽지 않을 것 같다. 원본을 변경하면서 풀이하는 방법이 있다고만 알아두자.
