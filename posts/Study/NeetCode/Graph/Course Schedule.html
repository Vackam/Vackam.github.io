선수 과목 목록이 주어질 때 강의를 수강할 수 있는 지 확인하라.

푸는 방법

위상 정렬을 활용하면 된다.

어렸을 때, "난 쟤보다 빠르고 쟤보단 느려"가 엄청 많아서 그럼 누가 1등인가? 하는 문제를 봤을 것이다. 그것과 아주 동일한 문제이다.

A가 B보다 앞선다는 것은 Directed Graph로 표현할 수 있다.

즉, 앞선 정보만 모아서 그래프로 표현하고, 이를 하나하나씩 풀어나가면 된다.

단, 이 문제에서는 말도 안되는 loop가 생길 수도 있다. 그래서 counter로 노드의 개수를 세어가며 진행했다.

다음은 코드이다.

class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> adj(numCourses);
        vector<int> in_degree(numCourses, 0);

        // first 가 나중에 들어도 되고, second가 선수과목
        for (auto& a : prerequisites) {
            adj[a[1]].emplace_back(a[0]);
            in_degree[a[0]]++;
        }

        queue<int> q;
        for (int i=0; i<numCourses; ++i) {
            if (in_degree[i] == 0) q.push(i);
        }

        int counter = 0;
        while (!q.empty()) {
            int c = q.front(); q.pop();
            counter++;
            for (int n : adj[c]) {
                in_degree[n]--;
                if (in_degree[n] == 0) q.push(n);
            }
        }

        if (counter != numCourses) return false;
        return true;
    }
};

인접 리스트를 만들어 준 후, 방향 그래프에서 들어오는 간선이 없는 노드만 집어낸다. 이후 이 노드를 삭제해가면서 계속 찾다 보면 끝에 까지 도달하게 되고, 도달을 못할 시 false를 날리게 된다.

결론

보자마자 위상정렬의 느낌이 왔는데, 위상정렬이란 단어가 기억이 안나서 풀이도 잘 안떠올랐다... 그리고 많이 공부했을 때도 어려워했던 것이라 좀 더 공부하도록 하자.
