그래프를 딥카피 해라.

푸는 방법

성실하게 딥카피 하면 된다.

다만, 자신의 이웃처리를 중복 생성하지 않고 기억하기 위해 기억하는 배열을 하나 추가하는 것이 핵심이다.

다음은 코드이다.


class Solution {
public:
    Node* cloneGraph(Node* node) {
        if (node == nullptr) return nullptr;
        Node* root = new Node(node->val);

        vector<bool> visited(101, false);
        vector<Node*> rem(101, nullptr);

        auto dfs = [&](auto& self, Node* node, Node* deep_copy) -> void {
            // 들어왔을 때는 동일한 노드가 들어온다고 가정. 즉 이미 처리함. 이웃만 처리해주기

            visited[node->val] = true;
            rem[node->val] = deep_copy;
            
            vector<Node*> nei;
            for (auto& a : node->neighbors) {
                if (visited[a->val]) {
                    nei.push_back(rem[a->val]);
                    continue;
                };

                Node* new_node = new Node(a->val); // 일단 만들고
                self(self, a, new_node); // 돌려서 nei 다 추가한 다음.
                nei.push_back(new_node); // 결과에 추가해주자. 
            }

            deep_copy->neighbors = nei;
        };

        dfs(dfs, node, root);

        return root;
    }
};

사실 여기서 visited와 rem 역할이 겹치기 때문에 rem 하나만 사용해도 가능하다.
