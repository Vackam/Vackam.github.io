Longest Increasing Subsequence

서론

가장 긴 증가하는 부분수열을 구하시오

푸는 방법

트래킹해서 부분수열 자체를 구하는 것이 아니라서 단순히 1차원 dp 하나로 풀린다.

1차원 dp를 두고 내 전 dp들을 훑으며 나보다 작은 값보다 1은 더한 값을 계속 비교하면서 나가면 된다.

다음은 코드이다.

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n+1, 1);

        for (int i=1; i<n; ++i) {
            for (int j=0; j<i; ++j) {
                int target = nums[j] < nums[i] ? dp[j] + 1 : 0;
                dp[i] = max(dp[i], target);
            }
        }

        return *max_element(dp.begin(), dp.end());
    }
};
