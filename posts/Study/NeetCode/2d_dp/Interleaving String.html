Interleaving String

2026-09-11 psdp

서론

| https://neetcode.io/problems/interleaving-string/question

주어진 두 개의 문자열을 모두 소진하여 목표하는 문자열을 만들 수 있는 지 판별하라

푸는 방법

2차원 dp로 풀면 된다.

dp[i][j] = a[i]와 b[j]까지 써서 target[i+j-1]까지 만들 수 있는가? 로 생각하고 풀면 된다.

이렇게 풀어야 하는 이유는 동일 문자가 나왔을 때, 어떤 문자를 사용할 지 알 수 없기 때문이다. 그래서 a로 된 경우 b로 된 경우를 추적할 수 있게 한다.

다음은 코드이다.

class Solution {
public:
    bool isInterleave(string a, string b, string target) {
        int n = a.size(), m = b.size();
        if (n+m != target.size()) return false;

        vector<vector<bool>> dp(n+1, vector<bool>(m+1, false));
        dp[0][0] = true;
        for (int i=0; i<=n; ++i) {
            for (int j=0; j<=m; ++j) {
                if (i > 0 && dp[i-1][j] && a[i-1] == target[i+j-1]) dp[i][j] = true;
                if (j > 0 && dp[i][j-1] && b[j-1] == target[i+j-1]) dp[i][j] = true;
            }
        }    

        return dp[n][m];
    }
};

여담

여담으로 다음 코드로도 풀린다. 아마 테스트 케이스가 부족해서 그런 것 같다.

class Solution {
public:
    bool isInterleave(string a, string b, string target) {
        int a_size = a.size();
        int b_size = b.size();
        if (a_size + b_size != target.size()) return false;

        int a_c = a_size - 1;
        int b_c = b_size - 1;

        for (int i=target.size() - 1; i>=0; --i) {
            auto t = target[i];
            if (a_c >= 0 && a[a_c] == t) {
                a_c--;
            } else if (b_c >= 0 && b[b_c] == t) {
                b_c--;
            } else {
                return false;
            }
        }        

        return true;
    }
};

이게 앞에서부터 target을 훑는 것에 대한 테스트 코드는 존재하는 데, 뒤로 도는 것에 대한 테스트 케이스가 없다. 그래서 통과는 된다.

결론

dp에 이름 지어주는 게 가장 어려운 듯하다.
