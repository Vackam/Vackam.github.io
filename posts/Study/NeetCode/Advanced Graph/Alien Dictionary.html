Alien Dictionary

서론

알파벳으로 새로운 순서의 사전이 주어졌을 때, 이 요소들을 정렬하시오

푸는 방법

우선 위상 정렬이 필요하다. a가 b보다 앞에 있고, c가 a보다 앞에 있고 ... 이런 식의 문제를 정렬하는 방법이다. 생각하는 방법은 간단한데, 잎에 있는 놈을 화살표로 찌르면 된다. 아무 화살표도 안 찔린 놈부터 제거해나가면 정렬이 된다.

이 위상 정렬을 알았으면 자료구조를 만들고 진행하면 된다.

붙어있는 두 단어만 비교하며, 처음으로 달라지는 부분을 체크한다.

이것을 기록하고, 기록한 후에는 비교할 수 없으므로(abc와 abdefg를 기본 사전 식으로 생각했을 때, c가 d보다 빠르다는 것을 얻은 다음에는 추가 정보를 얻을 수 없다. 즉 efg에 대한 정보가 없다.) 바로 다음으로 넘어간다. 이때 화살표를 찔러준다. (앞 예시에서 d를 찔러준다)

이후 khan 알고리즘으로 위상정렬을 진행해준다.

다음은 코드이다.

class Solution {
public:
    string foreignDictionary(vector<string>& words) {
        unordered_map<char, unordered_set<char>> adj;
        unordered_map<char, int> indeg;

        for (const string& w : words) {
            for (char c : w) {
                adj[c];
                indeg[c];
            }
        } 

        for (int i=0; i+1<words.size(); ++i) {
            const string& a = words[i];
            const string& b = words[i + 1];

            int len = min(a.size(), b.size());
            int j = 0;
            while (j<len && a[j] == b[j]) j++;

            if (j==len) {
                if (a.size() > b.size()) return "";
            } else {
                if (adj[a[j]].insert(b[j]).second) indeg[b[j]]++;
            }
        }

        queue<char> q;
        for (auto& [c, d] : indeg) {
            if (d == 0) q.push(c);
        }

        string res;
        while (!q.empty()) {
            char x = q.front(); q.pop();
            res += x;
            for (char y : adj[x]) {
                if (--indeg[y] == 0) q.push(y);
            }
        }

        return res.size() == indeg.size() ? res : "";
    }
};

위상 정렬은 화살표를 생각하고 풀도록 하자.
