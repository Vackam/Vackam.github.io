푸는 방법

정직하게 찾아보자.

다음은 코드이다.

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string result = "";

        int i = 0;
        while (true) {
            char target = strs[0][i];
            for (const auto& a : strs) {
                if (a.size() <= i) return result;
                if (a[i] != target) return result;
            }

            result += target;
            ++i;
        }

        return result;
    }
};

결론

저 함수 자체는 많이 맘에 안든다. 결국 while을 못 벗어나고 마지막 return 문을 들어가지 못한다.
