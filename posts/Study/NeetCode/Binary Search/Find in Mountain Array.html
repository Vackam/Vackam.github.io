Find in Mountain Array

2026-11-10 pstwo_pointer

서론

| https://neetcode.io/problems/find-in-mountain-array/question

극대점이 있는 배열에서 target이 있는 지 확인하라.

푸는 방법

peak를 이분 탐색으로 찾은 뒤, 그것을 기준으로 앞 뒤로 이분 탐색을 한 번 더 돌아준다.

다음은 코드이다.

class Solution {
public:
    int findInMountainArray(int target, MountainArray &arr) {
        int n = arr.length();

        // 피크: 기울기 기준 이분 탐색
        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr.get(mid) < arr.get(mid + 1)) lo = mid + 1;
            else hi = mid;
        }
        int peak = lo;

        int idx = search(arr, target, 0, peak, true);
        return idx != -1 ? idx : search(arr, target, peak + 1, n - 1, false);
    }

private:
    int search(MountainArray &arr, int target, int lo, int hi, bool asc) {
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int v = arr.get(mid);
            if (v == target) return mid;
            if ((v < target) == asc) lo = mid + 1;
            else hi = mid - 1;
        }
        return -1;
    }
};

원래는 삼분탐색으로 생각했었는데, 단순하게 기울기 기준으로 생각하면 되어서 이분 탐색으로 바꾸었다.
