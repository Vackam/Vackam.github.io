Target Sum

2026-09-10 psdp

서론

| https://neetcode.io/problems/target-sum/question

숫자 배열에서 모든 값을 더하거나 빼야할 때 target을 만드는 경우를 세시오. 단 순서가 중요합니다.

푸는 방법

i번째까지 가능한 숫자를 만드는 방법을 기록한다.

이후 i+1을 볼 때 이를 반영해서 만든다.

만약 i번째까지 3을 만드는 방법이 6가지면

i+1번째 값이 7일 때

10을 만드는 방법 -> 6

-4를 만드는 방법 -> 6

이런 식으로 진행했다.

다음은 코드이다.

class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        unordered_map<int, int> m;
        m[nums[0]] += 1;
        m[-nums[0]] += 1;

        for (int i=1; i<nums.size(); ++i) {
            int t = nums[i];
            unordered_map<int, int> temp;
            for (const auto& [k, v] : m) {
                temp[k - t] += v;
                temp[k + t] += v;
            }

            m = temp;
        }

        return m[target];
    }
};

이거 말고 부분합 변환도 있다.

+인 집합 P, -인 집합 N 이 있다고 하자.

P - N = 전체합

P + N = target

이 될 것이다.

그럼 P = (전체합 + target) / 2 이고, 즉 합이 저 값과 동일한 경우의 수를 세는 문제가 된다.

다음은 코드이다

class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int S = accumulate(nums.begin(), nums.end(), 0);
        if (abs(target) > S) return 0;
        if ((S + target) % 2 != 0) return 0;   // 홀수면 불가능

        int s = (S + target) / 2;
        vector<int> dp(s + 1, 0);
        dp[0] = 1;

        for (int x : nums)
            for (int j = s; j >= x; --j)
                dp[j] += dp[j - x];

        return dp[s];
    }
};
