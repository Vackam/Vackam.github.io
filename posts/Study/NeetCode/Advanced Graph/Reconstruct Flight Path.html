Reconstruct Flight Path

2026-09-01 psAdvanced-Graph

서론

| https://neetcode.io/problems/reconstruct-flight-path/history?list=neetcode150&submissionIndex=2

티켓을 모두 소진했을 때, 사전적으로 가장 빠른 소진 방법을 제시하라

푸는 방법

티켓을 전부 소진하는 방법이 무조건 존재한다고 가정하니 예외 상황은 처리 안해도 된다.

이게 숫자로 주어졌으면 굉장히 빠르게 풀 수 있을 거 같은데, 문자열로 주어져서 문제였다.

그래서 인코딩 디코딩 함수를 만들어서 풀도록 하자.

map을 하나 만들어서 출발지마다 갈 수 있는 곳을 티켓을 돌면서 확인하여 저장한다. 이때 저장할 때는 priority_queue 를 사용한다.

이후 JFK 공항부터 하나씩 꺼내보면서 경로를 탐색한다.

우선순위 큐 덕분에 사전 순으로 빠른 애들부터 나온다. 또한, 티켓을 다 소진하기 전에 더 이상 갈 수 없는 곳에 도착한다면, 이곳은 정황상 맨 마지막에 도착해야 하는 곳이므로 따로 저장한다. 이렇게 하나씩 제거하면서 나아가다 보면 답이 나온다.

다음은 코드이다. 

class Solution {
public:
    int enc(const string& a) {
        return (a[0] - 'A') * 676 + (a[1] - 'A') * 26 + (a[2] - 'A');
    }
    string dec(int x) {
        return {char('A' + x/676), char('A' + x/26%26), char('A' + x%26)};
    }
    vector<string> findItinerary(vector<vector<string>>& tickets) {
        unordered_map<int, priority_queue<int, vector<int>, greater<int>>> g;
        for (const auto& t : tickets) {
            g[enc(t[0])].push(enc(t[1]));
        }

        vector<int> route;
        vector<int> st = { enc("JFK") };

        while (!st.empty()) {
            int cur = st.back();
            auto it = g.find(cur); // it는 map 이터레이터임.
            if (it == g.end() || it->second.empty()) {
                route.push_back(cur);
                st.pop_back();
            } else {
                st.push_back(it->second.top());
                it->second.pop();
            }
        }

        reverse(route.begin(), route.end());

        vector<string> ans;
        ans.reserve(route.size());
        for (int x : route) ans.push_back(dec(x));

        return ans;
    }
};
