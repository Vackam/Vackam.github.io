Sum of Two Integers

2026-09-21 psbit-wise

서론

| https://neetcode.io/problems/sum-of-two-integers/question

덧셈과 뺄셈 없이 두 정수의 합을 구하시오

푸는 방법

전가산기를 만들면 된다.

(그림 1. 전가산기 수식, 출처: https://namu.wiki/w/%EA%B0%80%EC%82%B0%EA%B8%B0)

다음은 코드이다.

class Solution {
public:
    int getSum(int a, int b) {
        int ranker = 0;
        int result = 0;
        for (int i=0; i<32; ++i) {
            int a_temp = a & 1;
            int b_temp = b & 1;

            int sum = a_temp ^ b_temp ^ ranker;
            result |= sum << i;

            ranker = (a_temp & b_temp) | (a_temp & ranker) | (b_temp & ranker);
            
            a = a >> 1;
            b = b >> 1;
        }

        return result;
    }
};
