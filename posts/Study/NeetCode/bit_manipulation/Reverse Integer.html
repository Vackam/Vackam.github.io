Reverse Integer

2026-09-22 ps

서론

| https://neetcode.io/problems/reverse-integer/question?list=neetcode150

주어진 정수를 뒤집는데, 32bit 표현에서 벗어나면 0을 리턴하라

푸는 방법

stoi를 적극적으로 사용하고 에러가 나면 0을 반환한다.

다음은 코드이다.

class Solution {
public:
    int reverse(int x) {
        bool neg = x<0;
        string s = to_string(x);
        if (neg) s = s.substr(1);

        std::reverse(s.begin(), s.end());

        try {
            int result = stoi(s);
            return neg ? -result : result;
        } catch (const std::out_of_range&) {
            return 0;
        }
    }
};

이 풀이 말고도 long long에서 변환하면서 내려오기, 10씩 끊어서 확인하기 등이 있다.
