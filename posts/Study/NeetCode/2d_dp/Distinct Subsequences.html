Distinct Subsequences

2026-09-13 psdp

서론

| https://neetcode.io/problems/count-subsequences/question

만들 수 있는 구별되는 subsequence의 개수를 세어라

푸는 방법

dp[j] = 타겟 문자열의 j번째까지 만드는 경우의 수라고 가정하고, dp를 거꾸로 돌면서 순회하면 된다. dp를 거꾸로 순회하는 이유는 같은 문자의 경우 업뎃이 값의 영향을 끼치기 때문이다.

다음은 코드이다.

class Solution {
public:
    int numDistinct(string s, string t) {
        int n = s.size(), m = t.size();
        if (n < m) return 0;

        vector<int> dp(m+1, 0);
        dp[0] = 1;
        for (char c : s) {
            // 거꾸로 돌면서 찾기
            for (int j=m; j>=1; --j) {
                if (c == t[j-1]) {
                    dp[j] = dp[j] + dp[j-1];
                }
            }
        }

        return dp[m];
    }
};

dp를 문자열이 발견되면 그 전의 값과 더해주므로 해결한다.

결론

dp는 항상 답이 단순한데, 거기까지 가는 것이 너무 힘들다.
