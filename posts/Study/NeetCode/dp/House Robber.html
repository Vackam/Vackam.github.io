House Robber

2026-08-03 psdp

서론

| https://neetcode.io/problems/house-robber/question

인접한 집을 강탈할 수 없을 때, 최대한 집을 강탈할 방법을 찾으시오

푸는 방법

dp로 풀면 된다.

내 위치에서 내가 최대인 방법은

  1. 전 집에서 털고 우리 집을 쉰다
  2. 전 집에서 쉬고 우리 집을 턴다

둘 중에 최고인 하나를 찾으면 된다.

다음은 코드이다.

class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n<=2) return *max_element(nums.begin(), nums.end());
        vector<int> dp(n+1, 0);

        dp[0] = nums[0];        
        dp[1] = max(nums[0], nums[1]);        

        for (int i=2; i<n; ++i) {
            dp[i] = max(dp[i-2] + nums[i], dp[i-1]);
        }

        return dp[n-1];
    }
};
