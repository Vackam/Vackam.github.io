Asteroid Collision

2026-10-16 psqueuestack

서론

| https://neetcode.io/problems/asteroid-collision/question

소행성 충돌 후 결과를 기술하라.

푸는 방법

같은 방향인 것들은 절대로 만나지 않는다.

0부터 탐색했을 때, 처음 양수를 만날 때까지 앞에 있는 값들은 전부 충돌이 일어나지 않는다. 그러므로 바로 정답에 넣어주면 된다.

이후 정답의 top을 항상 양수로 설정해둔다. 이후 양수가 나온다면, 그것을 top으로 재설정하고, 음수가 나온다면 충돌 조건을 생각해 처리를 해준다.

다음은 코드이다.

class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        vector<int> s;
        for (int a : asteroids) {
            while (!s.empty() && a < 0 && s.back() > 0) {
                int diff = a + s.back();
                if (diff < 0) {
                    s.pop_back();
                } else if (diff > 0) {
                    a = 0;
                } else {
                    a = 0;
                    s.pop_back();
                }
            }

            if (a != 0) {
                s.push_back(a);
            }
        }
        return s;
    }
};

결론

처음에는 대충 막 풀었는데, 코드가 엄청 길었다. 저 while문의 3중 조건을 빠르게 캐치해 내는 게 중요했던 것 같다.
