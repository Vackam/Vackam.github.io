특이한 수열을 구해보자.

푸는 방법

n이 주어졌을 때, 1씩 증가하는 수열을 생각하자. 이는 {1, 2, 3, ... , n-1, n}이 될 것이다. 여기서 1은 항상 gcd(1, A[i]) == 1을 만족하기 때문에 k의 최댓값이 n-1임을 알 수 있다.

여기까지 왔으면 다음 두 가지 방식으로 풀 수 있다.

홀짝으로 스위칭 하기

인접한 두 정수는 무조건 서로소인 규칙을 사용해서 푸는 방식이다.

위에서 정의한 증가수열(이후 표기, a)에서 n-1 - k개 만큼의 서로소를 만들면 된다. 그렇다면, a에서 2씩 증가하면서 값들을 변경해나가면 된다.

다음은 코드이다.

#include <bits/stdc++.h>

using namespace std;

int main() {
  int n; cin >> n;
  int k; cin >> k;

  if (k == n) {
    cout << "Impossible";
    return 0;
  }

  vector<int> a(n+1);
  for (int i=1; i<=n; ++i) a[i] = i;

  int need = (n - 1) - k;
  int i = 2;

  while (need >= 2) {
    swap(a[i], a[i+1]);
    i += 2;
    need -= 2;
  }

  if (need == 1) swap(a[1], a[i]);

  for (int j=1; j<=n; ++j) cout << a[j] << " ";

  return 0;
}

k == n인 경우는 불가능하므로 예외처리를 해준다.

이후 a에서 필요한 만큼 swap을 하여 처리하고, 마지막에 한 개가 남았다면 1을 사용하여 바꿔준다.

그냥 밀기

똑같은 정의를 통해 a에서 n-k개만큼만 왼쪽으로 돌리는 것이다.

1 2 3 ... n-k-1 n-k | n-k+1 ... n
2 3 4 ...  n-k   1  | n-k+1 ... n

이런 식으로 막대기의 왼쪽 파트가 서로소 파트를 담당하고, 오른쪽 파트가 문제에서 요구한 조건 파트로 나누면 된다.

결론

처음에 n-1까지는 잘 갔는데, 다른 게 안되는 경우가 있나 해서 헤맸다. 인접한 두 정수가 서로소인 것을 항상 기억해야겠다.
