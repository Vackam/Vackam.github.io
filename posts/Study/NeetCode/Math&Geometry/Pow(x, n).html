Pow(x, n)

2026-09-29 psmath

서론

| https://neetcode.io/problems/pow-x-n/question

거듭제곱하는 함수를 만들어라

푸는 방법

정석은 재귀로 풀어야 한다.

재귀로 풀게 되면 곱하는 횟수가 log(n)회가 되므로 시간도 줄고 정확하게 판정할 수 있게 된다.

하지만, neet code는 조금 널널해서 조금은 더럽게 풀어봤다.

1인 특이케이스를 제외하고, INT_MIN의 절대값과 INT_MAX의 절대값이 차이나는 경우만 해결해 주었다.

다음은 코드이다.

class Solution {
public:
    double myPow(double x, int n) {
        // 예외
        if (x == 1.0) return x;
        if (x == -1.0) {
            if (n % 2 == 0) return 1.0;
            else return -1.0;
        }

        if (n == 0) {
            return 1.0;
        } else if (n < 0) {
            double result = 1;
            if (n == INT_MIN) {
                // 이때는 치환이 안되니까, MAX까지 돌고 해야함.
                // 근데 1보다 작은 값은 어차피 0이 되니까 값을 보고 판단하자.
                if (1/x < 1) return 0.0;
            }
            n = -n;
            x = 1/x;
            for (int i=0; i<n; ++i) {
                result *= x;
            }
            return result;
        } else {
            double result = 1;
            for (int i=0; i<n; ++i) {
                result *= x;
            }

            return result;
        } 

        return 1.0;
    }
};

결론

이상한 게, \(1^{INT\_MAX}\)는 시간 초과가 나고, \(2^{INT\_MIN}\)은 시간 초과가 안난다.
