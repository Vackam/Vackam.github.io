푸는 방법

아주 유명한 문제다.

이차원 dp를 세운 다음, 순회를 하면서 체크를 한다.

만약 s1과 s2가 같은 부분이 나온다면 대각성분에 +1을 해서 자신의 값으로 한다.

아니라면 왼쪽과 위쪽 중에서 가져온다.

다음은 코드이다.

class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<vector<int>> dp(m+1, vector<int>(n+1, 0));

        for (int i=1; i<=m; ++i) {
            for (int j=1; j<=n; ++j) {
                if (text1[i-1] == text2[j-1])
                    dp[i][j] = dp[i-1][j-1] + 1;
                else 
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
            }
        }

        return dp[m][n];
    }
};
