푸는 방법

만들어진 함수를 사용하는 것이 제일 좋다.

그게 아니라면, 매개변수를 이용한 binary search가 가능한 방법이다.

자주 나오는 포인트인데, binary search를 하되, 실제 판별하는 기준은 해당 값이 아니라 어떤 함수를 거친 값이라는 점이다.

이것이 가능하려면 어떤 함수가 선형적이어야 한다.

다음은 코드이다.

class Solution {
public:
    int mySqrt(int x) {
        if (x <= 1) return x;
        int s = 1, e = x;

        while (s < e) {
            long long mid = (s + e) / 2;

            long long mid_times = mid * mid;

            if (mid_times == x) {
                return mid;
            } else if (mid_times < x) {
                s = mid + 1;
            } else {
                e = mid;
            }
        } 

        return s - 1;
    }
};
