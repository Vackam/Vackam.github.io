푸는 방법

Longest Palindromic Substring

처음에 중복을 체크해야 할 거 같아서 set으로 하고 map으로 체크해보고 했는데, 전부다 시간 초과로 실패했다.

그래서 문제를 자세히 보니 중복을 허용하더라...

위 링크에서 푸는 방법 대로 돈다고 가정하면, 겹치는 {l, r} 쌍이 없다. 그러므로, 그냥 돌면서 하나하나 세면 정답이다.

다음은 코드이다.

class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        int count = 0;

        auto find = [&](int l, int r) {
            // 항상 l은 r 보다 작아야 함.
            int temp = r*1000 + l;
            while (l >= 0 && r < n && s[l] == s[r]) {
                count++;
                l--;
                r++;
            }
        };

        for (int i=0; i<n; ++i) {
            find(i, i); 
            find(i, i+1); 
        }

        return count;
    }
};
